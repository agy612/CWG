# 04. 번호 추천 알고리즘 명세

## 1. 개요

### 알고리즘의 목적

수집된 대량의 **낙첨 데이터**(= "이 번호 조합은 당첨되지 않았다"는 확실한 사실)를 분석하여, 통계적으로 유의미한 번호 추천 세트를 생성한다.

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **데이터 기반** | 추천은 반드시 수집된 실제 데이터에 근거해야 함 |
| **투명성** | 추천 근거(어떤 분석 기법이 적용됐는지)를 사용자에게 설명할 수 있어야 함 |
| **점진적 고도화** | 데이터 축적량에 따라 알고리즘 레벨이 올라감 |
| **당첨 보장 아님** | 추천은 통계 분석 결과이며, 당첨을 보장하지 않는다는 점 명시 필수 |

### CWG 픽생성(F4)과 챔피언십(F5)의 데이터 관계

본 알고리즘 명세는 두 기능의 공통 분석 데이터 기반을 정의한다.

| 구분 | CWG 픽생성 (F4) | 챔피언십 (F5) |
|------|---------------|--------------|
| **생성 주체** | 시스템이 자동 생성 (회차당 10개 고정) | 사용자가 직접 조절하여 생성 |
| **분석 데이터** | 본 명세의 Level 1~4 분석 결과 활용 | 동일한 분석 데이터를 활용 |
| **번호 결정 방식** | 알고리즘이 가중치와 조합을 자동 결정 | 사용자가 20개 필터의 가중치를 직접 조절 |
| **상세 문서** | 본 문서 (04_알고리즘_명세.md) | `10_커스텀_필터_번호생성.md` |

- **CWG 픽생성(F4):** 본 명세에 정의된 Level 1~4 알고리즘에 따라 시스템이 자동으로 추천 번호 세트를 생성하는 기능이다. **회차당 10개 번호 세트가 고정**으로 제공된다.
- **챔피언십(F5):** 동일한 분석 데이터(빈도, 패턴, 친화도 등)를 활용하되, 사용자가 20개 필터의 가중치를 직접 조절하여 자신만의 번호 조합을 생성하는 별도 기능이다. 상세 필터 정의 및 생성 로직은 `10_커스텀_필터_번호생성.md`를 참조한다.

### 데이터 양에 따른 알고리즘 레벨

```
데이터 축적량 ──────────────────────────────────────────→

Level 1          Level 2           Level 3           Level 4
기본 통계         패턴 분석          복합 모델          AI/ML 모델
(~1만 건)        (~10만 건)        (~100만 건)        (100만 건~)
│                │                 │                 │
▼                ▼                 ▼                 ▼
빈도 분석        연번/구간/홀짝     다변량 조합 분석   딥러닝 기반
단순 제외        패턴 분석          가중치 최적화      예측 모델
```

## 2. Level 1: 기본 통계 분석 (MVP)

> **필요 데이터:** ~1만 건 이상
> **적용 시점:** 서비스 출시 초기

> **MVP 무료 공개 항목:** Level 1의 기본 통계(최다 출현 번호, 최소 출현 번호)는 MVP에서 모든 사용자에게 무료로 공개되는 기본 통계 데이터의 원천이다. 즉, 앱의 "기본 통계" 화면에 표시되는 최다/최소 출현 정보는 아래 §2.1~§2.2의 빈도 분석과 핫넘버/콜드넘버 식별 결과에서 제공된다.

### 2.1. 번호별 출현 빈도 분석

**입력:** 수집된 낙첨 티켓의 번호 데이터
**분석:** 각 번호가 낙첨 티켓에서 얼마나 자주 선택되었는지 빈도 집계

```
[한국 로또 6/45 예시]

번호: 1  2  3  4  5  6  7  ... 44  45
빈도: 23 15 31 28 19 22 35  ... 17  20
비율: 5% 3% 7% 6% 4% 5% 8%     4%  5%
```

### 2.2. 핫넘버 / 콜드넘버 식별

| 구분 | 정의 | 추천 활용 |
|------|------|----------|
| **핫넘버 (Hot)** | 최근 N회차에서 출현 빈도가 평균 대비 1.5σ 이상인 번호 | 지속 출현 가능성 반영 |
| **콜드넘버 (Cold)** | 최근 N회차에서 출현 빈도가 평균 대비 -1.5σ 이하인 번호 | 회귀 가능성 반영 |
| **듀넘버 (Due)** | 출현 주기 대비 오랫동안 나오지 않은 번호 | 확률적 회귀 반영 |

### 2.3. Level 1 추천 생성 로직

```
입력: 최근 N회차(기본 50회) 낙첨 데이터
출력: 6개 번호로 구성된 추천 세트 3개

Step 1: 번호별 빈도 집계
Step 2: 핫넘버 상위 15개, 콜드넘버 하위 10개 식별
Step 3: 추천 세트 구성
  - 세트 A (공격형): 핫넘버 4개 + 듀넘버 2개
  - 세트 B (균형형): 핫넘버 3개 + 중립 2개 + 콜드넘버 1개
  - 세트 C (역발상): 콜드넘버 3개 + 듀넘버 2개 + 핫넘버 1개
Step 4: 각 세트 내 중복 제거, 번호 범위 유효성 검증
```

## 3. Level 2: 패턴 분석 (Phase 2)

> **필요 데이터:** ~10만 건 이상
> **적용 시점:** 서비스 운영 3~6개월

### 3.1. 구간 분포 분석

번호를 구간으로 나누어 분포를 분석한다.

```
[한국 로또 6/45 — 5구간]

구간 1: 1~9    (한 자리)
구간 2: 10~19
구간 3: 20~29
구간 4: 30~39
구간 5: 40~45

[최근 당첨 번호 구간 분포 분석]
당첨: 보통 3~4개 구간에 걸쳐 분포
낙첨: 1~2개 구간에 치우친 조합이 다수

→ 추천 시 최소 3개 구간에 걸치도록 제약 조건 적용
```

### 3.2. 연번 (Consecutive Number) 패턴

```
연번 = 연속된 두 수 (예: 7-8, 23-24)

분석 결과 (예시):
- 당첨 번호에 연번 포함 확률: ~40%
- 연번 2쌍 이상 포함: ~8%

→ 추천 세트에 연번 0~1쌍 포함하도록 조정
```

### 3.3. 홀짝 비율 분석

```
6개 번호의 홀수/짝수 비율:

비율      당첨 출현 빈도
홀6:짝0    1.2%
홀5:짝1    8.5%
홀4:짝2    23.1%   ★
홀3:짝3    34.7%   ★★ (가장 빈번)
홀2:짝4    22.8%   ★
홀1:짝5    8.2%
홀0:짝6    1.5%

→ 추천 세트는 홀3:짝3 또는 홀4:짝2, 홀2:짝4로 구성
```

### 3.4. 합계 범위 분석

```
6개 번호의 합계 분석:

최소 가능: 1+2+3+4+5+6 = 21
최대 가능: 40+41+42+43+44+45 = 255
평균: 138

당첨 번호 합계 분포:
- 100~170 구간에 ~70% 집중

→ 추천 세트의 번호 합이 100~170 범위가 되도록 필터링
```

### 3.5. Level 2 추천 생성 로직

```
입력: 최근 100회차 낙첨 데이터 + 당첨 결과
출력: 5개 추천 세트

Step 1: Level 1 분석 (핫/콜드/듀넘버)
Step 2: 패턴 필터 적용
  - 구간 분포: 최소 3개 구간에 걸칠 것
  - 연번: 0~1쌍만 허용
  - 홀짝: 3:3 또는 4:2 또는 2:4
  - 합계: 100~170 범위
Step 3: 후보 조합 생성 (1000개)
Step 4: 패턴 필터 통과하는 조합만 선별
Step 5: 빈도 점수 기준 상위 5세트 선정
```

## 4. Level 3: 복합 모델 (Phase 3)

> **필요 데이터:** ~100만 건 이상
> **적용 시점:** 서비스 운영 6~12개월

### 4.1. 낙첨 제외 기반 역추론

**핵심 아이디어:** 대량의 낙첨 데이터 = "이 조합은 아니다"라는 확실한 정보

```
전체 가능 조합: C(45,6) = 8,145,060가지 (로또 6/45 기준)

수집된 낙첨 조합: 50만 가지 (예시)
→ 전체의 약 6.1%를 "확실한 낙첨"으로 제거 가능

나머지 조합 중에서 패턴 분석을 적용하면
후보 조합 풀이 크게 축소됨
```

### 4.2. 조합 친화도 (Number Affinity) 분석

```
두 번호가 함께 출현하는 빈도 분석 (공출현 매트릭스)

예시:
  번호 7과 13이 함께 나온 빈도: 높음 (친화도 ↑)
  번호 7과 38이 함께 나온 빈도: 낮음 (친화도 ↓)

→ 친화도가 높은 번호 쌍을 우선 조합
→ 반대로, 당첨에서 친화도 높은 쌍 vs 낙첨에서 친화도 높은 쌍을 구분
```

### 4.3. 가중치 스코어링 모델

각 분석 기법에 가중치를 부여하여 최종 점수를 산출한다.

```
최종 점수(조합) = w1 × 빈도점수
               + w2 × 구간분포점수
               + w3 × 연번점수
               + w4 × 홀짝점수
               + w5 × 합계범위점수
               + w6 × 친화도점수
               + w7 × 낙첨제외보너스

가중치 (w1~w7)은 과거 적중률 기반으로 주기적 조정
```

## 5. Level 4: AI/ML 모델 (Phase 4)

> **필요 데이터:** 100만 건 이상
> **적용 시점:** 서비스 운영 12개월 이후

### 5.1. 가능한 접근법

| 모델 | 설명 | 활용 |
|------|------|------|
| **LSTM (시계열)** | 회차별 번호 출현 패턴의 시계열 분석 | 다음 회차 출현 확률 예측 |
| **Collaborative Filtering** | 유사 패턴의 사용자 그룹 분석 | 개인 맞춤 추천 |
| **Ensemble** | Level 1~3 모델의 앙상블 | 다수 모델의 합의(consensus) 기반 추천 |

### 5.2. 개인 맞춤 추천 (구독자 전용)

```
입력: 해당 사용자의 과거 구매 번호 패턴 (10건 이상)
분석:
  - 사용자가 선호하는 번호 대역
  - 사용자의 번호 선택 패턴 (생일, 기념일 등)
  - 해당 패턴과 전체 데이터의 교차 분석

출력: 사용자 취향을 반영한 개인화 추천 세트
```

## 6. 알고리즘 적중 평가

### 6.1. 적중 기준

| 적중 등급 | 기준 (6개 중) | 표시 |
|----------|:---:|------|
| 완전 적중 | 6개 | ⭐⭐⭐⭐⭐ (사실상 1등) |
| 고적중 | 5개 | ⭐⭐⭐⭐ |
| 우수 적중 | 4개 | ⭐⭐⭐ |
| 부분 적중 | 3개 | ⭐⭐ |
| 경미 적중 | 2개 | ⭐ |
| 미적중 | 0~1개 | - |

### 6.2. 적중률 공개 정책

```
[추천 탭 > 적중 이력]

회차     추천세트   적중 번호    등급
#1158    세트 A    3/6개     ⭐⭐
#1158    세트 B    2/6개     ⭐
#1157    세트 A    4/6개     ⭐⭐⭐    ← 하이라이트
...

평균 적중률 (최근 20회):
  3개 이상 적중: 32%
  4개 이상 적중: 8%
```

- **마케팅 활용:** "지난달 추천 세트 중 4개 이상 적중 8회 달성!"
- **투명성:** 미적중 결과도 숨기지 않고 전체 공개

| 선택 개수 | 6 | 5 + 1 | 6 |

## 8. 데이터 파이프라인

```
[데이터 수집]          [데이터 가공]         [알고리즘 실행]      [결과 제공]

티켓 스캔 ──→ raw_extracted_data ──→ 정제/집계 ──→ 추천 세트 생성 ──→ 사용자 열람
                      │                    │                    │
추첨 결과 연동 ──→ draw_results ──────→ 적중 평가 ──→ 적중 이력 기록
                                          │
                                    가중치 재조정
                                    (w1~w7 튜닝)
```

### 배치 스케줄

| 작업 | 주기 | 시점 (한국 기준) |
|------|------|----------------|
| 추첨 결과 수집 | 추첨일 | 토요일 21:00 이후 |
| 낙첨 데이터 집계 | 일간 | 매일 03:00 |
| 추천 세트 생성 | 주간 | 일요일 06:00 (새 회차 시작 후) |
| 적중 평가 | 추첨 후 | 토요일 22:00 |
| 가중치 재조정 | 월간 | 매월 1일 |
| 알고리즘 레벨 평가 | 분기 | 분기별 데이터 양 체크 |
