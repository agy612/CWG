## 1. 개요

### 1.1 기획 목적

**왜 이 기능이 필요한가?**
- 특별 프로모션 이벤트를 효과적으로 전달
- 신규 가입자 및 기존 사용자 리텐션 향상
- 포인트, 쿠폰, 티켓, 구독 할인 등 다양한 혜택 제공

**해결하고자 하는 문제**
- 사용자가 진행 중인 이벤트를 놓치는 경우
- 프로모션 혜택에 대한 인지도 부족
- 앱 재방문 동기 부여

### 1.2 표시 시점

**팝업이 표시되는 타이밍**
- 앱 진입 시 자동 표시 (우선순위 높음)
- 특정 액션 완료 후 (예: 첫 스캔 완료, 구독 전환 시도 시)
- 프로모션별 설정된 트리거 조건 충족 시

### 1.3 타겟팅

**대상 사용자 설정**
- 전체 회원
- 신규 가입자 (가입 후 N일 이내)
- 특정 등급 (FREE, STANDARD, PRO)
- 비활성 사용자 (N일 이상 미접속)

## 2. 팝업 공통 구조

모든 프로모션 팝업은 다음 요소를 공통으로 포함합니다.

### 2.1 레이아웃 구성

```
┌───────────────────────────────────────┐
│  [배경 오버레이: 반투명 검정 + 블러]   │
│                                       │
│   ┌─────────────────────────────┐    │
│   │  [팝업 창]                  │ ×  │
│   ├─────────────────────────────┤    │
│   │                             │    │
│   │  🎁 특별 프로모션!           │    │
│   │                             │    │
│   │  [배너 이미지]               │    │
│   │  (선택적)                    │    │
│   │                             │    │
│   │  신규 가입 환영 이벤트!       │    │
│   │                             │    │
│   │  ✨ 1,000P 즉시 지급        │    │
│   │  ✨ 챔피언십 티켓 3회 무료   │    │
│   │                             │    │
│   │  첫 로또 구매를 축하합니다.   │    │
│   │                             │    │
│   │  [받기] [나중에]             │    │
│   │                             │    │
│   │  □ 오늘 하루 보지 않기       │    │
│   └─────────────────────────────┘    │
│                                       │
└───────────────────────────────────────┘
```

### 2.2 구성 요소 상세

**1. 배경 오버레이**
- 반투명 검정 배경으로 기존 화면 차단
- 블러 효과 적용하여 초점을 팝업에 집중

**2. 팝업 헤더**
- 타이틀: "🎁 특별 프로모션!" (고정)
- 닫기 버튼(×): 우상단에 배치

**3. 배너 이미지** (선택사항)
- 어드민에서 업로드한 프로모션 배너
- 없을 경우 생략 (텍스트만 표시)
- 권장 크기: 가로 전체 × 세로 200px
- 형식: JPEG, PNG

**4. 프로모션 제목**
- 어드민에서 설정한 제목
- 예: "신규 가입 환영 이벤트!", "3월 특별 할인"
- 크기: 20px, 굵기: Bold

**5. 혜택 목록**
- "✨" 이모지와 함께 혜택 항목 나열
- 최대 3개 항목 권장
- 예:
  - ✨ 1,000P 즉시 지급
  - ✨ 챔피언십 티켓 3회 무료
  - ✨ Standard 구독 첫 달 30% 할인

**6. 설명 텍스트**
- 부가 설명 (선택사항)
- 예: "첫 로또 구매를 축하합니다.", "이벤트 기간: 3월 1일~31일"
- 크기: 14px, 색상: 회색

**7. 액션 버튼 (2개)**
- **주 액션**: "받기" / "쿠폰 받기" / "할인 받기"
  - 배경: 흰색
  - 텍스트: 검정, 굵기: Bold
  - 크기: 전체 너비, 높이 48px
- **부 액션**: "나중에"
  - 배경: 투명
  - 텍스트: 회색
  - 크기: 전체 너비, 높이 40px

**8. "오늘 하루 보지 않기" 체크박스**
- 팝업 하단에 배치
- 체크 시: 해당 프로모션을 24시간 동안 미표시
- 로컬 저장소에 기록 (promo_id + 날짜)

## 3. 프로모션 유형별 기능

### 3.1 유형 1: 포인트 지급 (POINT)

**목적**: 즉시 포인트를 지급하여 사용자 활동 유도

**혜택 표시 예시**
- ✨ 1,000P 즉시 지급
- ✨ 신규 가입 축하 500P

**사용자 플로우**
1. 팝업 표시: "🎁 특별 프로모션!"
2. 사용자가 "받기" 버튼 탭
3. 즉시 포인트 지급
4. 팝업 닫힘
5. 토스트 메시지: "1,000P가 지급되었습니다"

**제약사항**
- 1회 수령 제한 (중복 수령 불가)
- 포인트 유효기간: 지급일로부터 12개월

---

### 3.2 유형 2: 쿠폰 지급 (COUPON)

**목적**: 쿠폰을 자동 등록하여 구매 전환 유도

**혜택 표시 예시**
- ✨ 챔피언십 무료 티켓 쿠폰
- ✨ Standard 구독 20% 할인 쿠폰
- 쿠폰 코드: CHAMP2026

**사용자 플로우**
1. 팝업 표시: 쿠폰 코드 표시
2. 사용자가 "쿠폰 받기" 버튼 탭
3. 쿠폰 자동 등록 (마이 탭 > 쿠폰함에 저장)
4. 팝업 닫힘
5. 토스트 메시지: "쿠폰함에 등록되었습니다"

**쿠폰 정보**
- 쿠폰명: 어드민 설정
- 쿠폰 코드: 자동 생성 또는 수동 설정
- 유효기간: 등록일로부터 N일
- 사용처: 포인트샵, 구독 결제 등

---

### 3.3 유형 3: 무료 티켓 지급 (TICKET)

**목적**: 챔피언십 티켓을 지급하여 기능 체험 유도

**혜택 표시 예시**
- ✨ 챔피언십 3회 무료 티켓
- ✨ 챔피언십 1회 체험권

**사용자 플로우**
1. 팝업 표시: 티켓 개수 표시
2. 사용자가 "받기" 버튼 탭
3. 챔피언십 티켓 지급 (보유 티켓에 추가)
4. 팝업 닫힘
5. 토스트 메시지: "챔피언십 탭에서 확인하세요"

**티켓 정보**
- 지급 개수: 1~10회
- 유효기간: 지급일로부터 30일
- 사용처: 챔피언십 번호 생성 시 차감

---

### 3.4 유형 4: 구독 할인 (DISCOUNT)

**목적**: 구독 전환을 유도하기 위한 할인 혜택 제공

**혜택 표시 예시**
- ✨ Standard 첫 달 30% 할인 (₩5,000 → ₩3,500)
- ✨ Pro 첫 달 50% 할인 (₩8,000 → ₩4,000)

**사용자 플로우**
1. 팝업 표시: 할인율 및 할인가 표시
2. 사용자가 "할인 받기" 버튼 탭
3. 구독 화면으로 이동
4. 할인 쿠폰 자동 적용
5. 구독 결제 시 할인가로 결제

**할인 정보**
- 할인율: 10%, 20%, 30%, 50% 등
- 적용 대상: Standard 또는 Pro 구독
- 적용 기간: 첫 달 또는 N개월
- 자동 적용: 구독 화면에서 할인 쿠폰 자동 선택

## 4. 사용자 인터랙션

### 4.1 "받기" / "쿠폰 받기" / "할인 받기" 버튼

**정상 동작**
1. 버튼 탭
2. 혜택 지급 처리 (포인트, 쿠폰, 티켓)
3. 팝업 닫힘 (페이드 아웃 애니메이션)
4. 토스트 메시지 표시 (하단에서 올라오는 애니메이션)

**에러 처리**
- 중복 수령 시: "이미 받은 프로모션입니다." 표시 (팝업 유지)
- 네트워크 오류 시: "잠시 후 다시 시도해주세요." 표시 (팝업 유지)
- 유효기간 만료 시: "종료된 이벤트입니다." 표시 후 팝업 닫힘

### 4.2 "나중에" 버튼

**동작**
1. 버튼 탭
2. 팝업 닫힘
3. 다음 앱 진입 시 조건 충족 시 재표시

**표시 조건**
- 프로모션 기간 내
- "오늘 하루 보지 않기" 미체크 상태
- 수령하지 않은 경우

### 4.3 "×" 닫기 버튼

**동작**
- "나중에" 버튼과 동일한 동작
- 우상단 × 아이콘 탭 시 팝업 닫힘

### 4.4 "오늘 하루 보지 않기" 체크박스

**동작**
1. 체크박스 선택
2. "나중에" 또는 "×" 버튼 탭
3. 로컬 저장소에 기록 (promo_id + 오늘 날짜)
4. 다음 날 자정(00:00) 이전까지 해당 프로모션 미표시
5. 다음 날 자정 이후 다시 표시 가능

**저장 정보**
- promo_id: 프로모션 고유 ID
- hidden_date: 숨김 날짜 (YYYY-MM-DD)
- 만료 시점: 다음 날 00:00

## 5. 비즈니스 로직

### 5.1 복수 프로모션 처리

**우선순위 규칙**
- 여러 프로모션이 동시에 활성화된 경우
- 우선순위 높은 순으로 1개씩 순차 표시
- 또는 서버에서 1개만 응답 (어드민 설정)

**우선순위 예시**
1. 신규 가입자 환영 이벤트 (최우선)
2. 구독 할인 이벤트
3. 포인트 지급 이벤트
4. 일반 프로모션

### 5.2 표시 빈도 제어

**기본 설정**
- 1일 1회 표시 (동일 프로모션)
- "오늘 하루 보지 않기" 선택 시 24시간 미표시

**예외 케이스**
- 긴급 공지: 무조건 표시 (설정 무시)
- 고가치 이벤트: 1일 2회 표시 가능 (어드민 설정)

### 5.3 프로모션 기간

**표시 조건**
- 시작일: 프로모션 시작일 00:00부터 표시
- 종료일: 프로모션 종료일 23:59까지 표시
- 기간 외: 팝업 미표시

**타임존**
- 한국: KST (UTC+9)
- 일본: JST (UTC+9)
- 유럽: CET (UTC+1)

### 5.4 수령 제한

**1회 수령**
- 대부분의 프로모션: 사용자당 1회 수령
- 중복 수령 시도 시 에러 메시지

**무제한 수령** (예외)
- 일일 출석 이벤트: 매일 1회 수령 가능
- 광고 시청 보상: 무제한 (일일 한도 내)

### 5.5 타겟팅 조건

**신규 가입자**
- 가입 후 7일 이내
- 첫 로그인 시 표시

**등급별**
- FREE 전용: FREE 사용자에게만 표시
- STANDARD/PRO: 구독자 제외 (FREE만 대상)

**비활성 사용자**
- 최근 30일 미접속 사용자
- 재방문 시 표시

## 6. 디자인 가이드

### 6.1 레이아웃

**팝업 크기**
- 너비: 화면의 90% (최대 400px)
- 높이: 컨텐츠에 따라 가변 (최대 80vh)
- 모서리 둥글기: 20px

**내부 여백**
- 상하좌우: 24px
- 버튼 간 간격: 12px

### 6.2 색상

**배경 오버레이**
- 색상: #000000
- 투명도: 70%

**팝업 배경**
- 색상: #1a1a1a (다크 모드)
- 테두리: 1px #2a2a2a

**주 액션 버튼**
- 배경: #ffffff
- 텍스트: #000000
- 호버: #f0f0f0

**부 액션 버튼**
- 배경: 투명
- 텍스트: #a1a1a1
- 호버: #8a8a8a

### 6.3 타이포그래피

**팝업 타이틀**
- 크기: 18px
- 굵기: Bold (700)

**프로모션 제목**
- 크기: 20px
- 굵기: Bold (700)

**혜택 항목**
- 크기: 16px
- 굵기: SemiBold (600)

**설명 텍스트**
- 크기: 14px
- 굵기: Regular (400)
- 색상: #a1a1a1

**버튼 텍스트**
- 크기: 16px
- 굵기: Bold (700)

### 6.4 애니메이션

**팝업 등장**
- 페이드 인 + 스케일 업 (0.9 → 1.0)
- 지속 시간: 300ms
- Easing: ease-out

**팝업 닫힘**
- 페이드 아웃 + 스케일 다운 (1.0 → 0.9)
- 지속 시간: 200ms
- Easing: ease-in

**버튼 탭**
- 스케일: 0.95배 축소
- 지속 시간: 100ms
