# CWG 앱 — 온보딩 화면 (Onboarding) Figma Make 프롬프트

## 화면 목적

앱 최초 실행 시 로또 선택 후 표시되는 3단계 슬라이드 화면.
앱의 핵심 가치 3가지(스캔, CWG 픽생성, 챔피언십)를 소개하고 회원가입으로 유도.

---

## 진입 경로

- 앱 최초 실행 + 로또 선택 완료 후 (미가입 상태)
- 이미 온보딩을 완료한 사용자는 이 화면을 건너뜀 (로컬 저장소 `onboarding_completed` 플래그 확인)

---

## 필수 기능 요소

### 1. 공통 요소 (3개 슬라이드 공통)

- **우상단 "건너뛰기" 버튼:** 어느 슬라이드에서든 탭하면 즉시 회원가입 화면으로 이동
- **하단 페이지 인디케이터 (●○○ / ○●○ / ○○●):** 현재 슬라이드 위치 표시, 탭으로 해당 슬라이드로 이동 가능
- **"다음" 버튼 (1·2번 슬라이드) / "시작하기" 버튼 (3번 슬라이드):** 다음 슬라이드 또는 회원가입으로 이동
- 좌우 스와이프로 슬라이드 간 이동 가능

---

### 2. 슬라이드 1/3 — 스캔

- **아이콘:** 카메라(📸)
- **제목:** "낙첨 복권을 스캔하세요"
- **설명:** "낙첨된 복권도 가치가 있어요. 스캔하면 포인트로 돌려받아요!"
- **버튼:** "다음 →" → 슬라이드 2로 이동

---

### 3. 슬라이드 2/3 — CWG 픽생성

- **아이콘:** 타겟(🎯)
- **제목:** "CWG 픽을 받아보세요"
- **설명:** "수집된 데이터를 분석해서 매주 새로운 추천 번호를 제공해드려요."
- **버튼:** "다음 →" → 슬라이드 3으로 이동

---

### 4. 슬라이드 3/3 — 챔피언십

- **아이콘:** 트로피(🏆)
- **제목:** "나만의 번호를 만들어보세요"
- **설명:** "챔피언십에서 20개 필터를 조절해서 자신만의 번호를 뽑아보세요!"
- **버튼:** "시작하기" → 회원가입 화면으로 이동

---

## 화면 전환

| 조건 | 이동 화면 |
|------|----------|
| "건너뛰기" 탭 | 회원가입 화면 |
| 슬라이드 3 "시작하기" 탭 | 회원가입 화면 |

---

## 상태 관리

- 온보딩 완료 시 로컬 저장소에 `onboarding_completed: true` 저장
- 이후 앱 재실행 시 온보딩 표시하지 않음
