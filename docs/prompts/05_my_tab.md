# CWG 앱 — 마이 탭 (My Tab) Figma Make 프롬프트

## 화면 목적

사용자 프로필 확인, 포인트 내역 조회, 구독 상태 확인 및 앱 설정을 위한 탭.
포인트샵·구독 관리·쿠폰함·럭키/제외 번호 설정·고객센터 진입점.

---

## 진입 경로

- 하단 탭 네비게이션 > "마이"

---

## 필수 기능 요소

### 1. 헤더

- "마이" 제목
- 우측에 설정 아이콘(⚙️) → 설정 화면 이동

---

### 2. 프로필 카드

- **프로필 이미지:** 기본 아이콘(👤), 탭 시 프로필 편집 바텀시트 (닉네임 변경, 이미지 업로드)
- **닉네임:** 사용자 닉네임 표시
- **티어 배지:** FREE / STANDARD 🏅 / PRO 🏅 (티어별 색상 구분)
- **가입일:** "가입일: YYYY-MM-DD"

---

### 3. 포인트 카드

- **"💰 내 포인트"** 라벨
- **포인트 잔액:** 크게 표시 (예: 1,500 P, 천 단위 콤마)
- **"거래 내역 보기" 버튼** → 포인트 거래 내역 화면 이동
- 카드 전체 탭 시에도 포인트 거래 내역 화면으로 이동

---

### 4. 이번 달 스캔 통계 카드

- **"📊 이번 달 스캔 통계"** 라벨
- **이번 달 스캔 횟수** (예: 25회)
- **이번 달 획득 포인트** (예: 1,875P)
- 카드 탭 시 스캔 통계 상세 화면으로 이동 (월별 스캔 그래프, 획득 포인트 추이)
- **빈 상태:** "아직 스캔 기록이 없어요. 첫 스캔을 시작해보세요!" 안내

---

### 5. 메뉴 리스트

각 항목은 탭 시 해당 화면으로 이동:

1. **🏪 포인트샵** → 포인트샵 화면
2. **💳 구독 관리** (FREE면 "구독하기" 라벨) → 구독 화면
3. **🎫 쿠폰함** → 쿠폰함 화면
4. **🍀 럭키/제외 번호** → 럭키/제외 번호 설정 화면
5. **❓ 고객센터** → 고객센터 화면 (FAQ, 1:1 문의)

---

### 6. 앱 정보 및 로그아웃

- **앱 버전 표시** (예: "버전: 1.0.0")
- **"로그아웃" 버튼:** 빨간 텍스트, 탭 시 확인 다이얼로그 표시
  - 다이얼로그: "정말 로그아웃하시겠어요?"
  - "취소" / "로그아웃" 버튼
  - 로그아웃 시 Access Token + Refresh Token 삭제 → 로또 선택 화면으로 이동

---

## 럭키/제외 번호 설정 화면 (별도 화면)

마이 탭 > 럭키/제외 번호 메뉴에서 진입하는 서브 화면:

- **럭키 번호 (선택, 최대 5개):**
  - 설정된 번호들을 칩(chip) 형태로 표시
  - "+" 버튼 탭 → 번호 선택 바텀시트 (1~45 그리드)
  - 챔피언십에서 우선 포함되는 번호
- **제외 번호 (선택, 최대 10개):**
  - 설정된 번호들을 칩 형태로 표시
  - "+" 버튼 탭 → 번호 선택 바텀시트
  - 챔피언십에서 제외되는 번호
- **"저장" 버튼:** `PUT /api/v1/users/me/preferences` 호출

---

## 포인트 거래 내역 화면 (별도 화면)

포인트 카드 탭 시 진입하는 서브 화면:

- 거래 내역 목록 (무한 스크롤, 페이지당 20건)
- 각 항목:
  - 거래 유형 (적립/차감)
  - 금액 (+ 또는 - 표시)
  - 내역 설명 (예: "복권 스캔 보상", "CWG 픽 열람")
  - 거래 후 잔액 (balance_after)
  - 거래 일시
- **빈 상태:** "거래 내역이 없어요"

---

## 예외/에러 상태

### 포인트 0원

- 포인트 잔액 "0 P" 표시
- 거래 내역 없음 안내

### FREE 사용자 메뉴

- "구독 관리" → "구독하기" 라벨로 표시

### 네트워크 오류

- "⚠️ 데이터를 불러올 수 없어요. 네트워크 연결을 확인해주세요."
- "다시 시도" 버튼

## API 연동

**사용자 프로필 조회:** `GET /api/v1/users/me`
- 응답: user_id, nickname, tier, point_balance, profile_image_url, created_at, monthly_scans, monthly_points_earned

**포인트 거래 내역:** `GET /api/v1/points/transactions?page={n}&size=20`
- 응답: transactions 배열, total_count, page, total_pages

**럭키/제외 번호 조회:** `GET /api/v1/users/me/preferences`

**럭키/제외 번호 저장:** `PUT /api/v1/users/me/preferences`

**로그아웃:** `POST /api/v1/auth/logout`
