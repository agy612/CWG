# CWG 앱 — 챔피언십 탭 (Championship) Figma Make 프롬프트

## 화면 목적

사용자가 20개 필터 슬라이더를 직접 조절하여 자신만의 번호를 생성하는 탭.
빠른 전략 프리셋 6개 제공, 전략 저장·재사용 가능.
번호 생성 결과 화면에서 번호 특성 분석도 표시.

---

## 진입 경로

- 하단 탭 네비게이션 > "챔피언십"
- 홈 화면 "챔피언십 배너" > "시작하기" 버튼

## 필수 기능 요소

### 1. 헤더

- "🏆 챔피언십" 제목
- "나만의 전략으로 번호를 만들자!" 부제
- 현재 선택된 로또명 + 회차 (예: "로또 6/45 · 제1159회")

---

### 2. 빠른 전략 프리셋 (6개)

탭 시 관련 필터값이 자동으로 세팅됨:

| 프리셋 | 설명 | 자동 세팅 필터 |
|--------|------|--------------|
| 🔥 트렌드 | 최근 많이 나온 번호 중심 | 핫넘버 80, 홀짝균형 90, 이전당첨포함 70 |
| 🧊 역발상 | 안 나온 번호 중심 | 콜드넘버 80, 이전당첨제외 80, 듀넘버 70 |
| ⚖️ 균형 | 골고루 분포 | 홀짝균형 100, 고저균형 100, 구간분포 80 |
| 🎯 수학 | 수학적 패턴 | AC값 80, 소수비율 70, 합계범위 80 |
| 🍀 내번호 | 행운번호 우선 반영 | 행운번호포함 100, 내이전번호제외 80 |
| 커스텀 | 전체 초기화 | 모든 필터 0 (직접 조절) |

---

### 3. 전략 필터 20개 (카테고리별 슬라이더)

각 필터는 0~100 범위 슬라이더로 조절. 값 0이면 해당 필터 비활성.

**[A] 빈도 필터 (4개)**
1. 핫넘버 (HOT_NUMBER) — 자주 나온 번호 선호 강도
2. 콜드넘버 (COLD_NUMBER) — 안 나온 번호 선호 강도
3. 듀넘버 (DUE_NUMBER) — 오래 안 나온 번호 강도
4. 빈도 균형 (FREQUENCY_BALANCE) — 출현빈도 균등 분포 강도

**[B] 패턴 필터 (6개)**
5. 홀짝 균형 (ODD_EVEN) — 홀수/짝수 비율 균등 강도
6. 고저 균형 (HIGH_LOW) — 높은/낮은 번호 비율 강도
7. 연번 포함 (CONSECUTIVE) — 연속된 번호 포함 강도
8. 구간 분포 (SECTION_SPREAD) — 번호 구간 분산 강도
9. 번호 간격 (NUMBER_GAP) — 번호 간 간격 균등 강도
10. 끝자리 배치 (EDGE_NUMBER) — 1·최대값 근처 번호 포함 강도

**[C] 수학 필터 (4개)**
11. 합계 범위 (SUM_RANGE) — 6개 번호 합계 범위 제약 강도
12. 소수 비율 (PRIME_RATIO) — 소수 포함 비율 강도
13. AC값 (AC_VALUE) — AC값 조건 강도
14. 끝자리 다양성 (LAST_DIGIT_VARIETY) — 끝자리 다양성 강도

**[D] 이력 필터 (3개)**
15. 이전 당첨 포함 (PREV_WINNER_INCLUDE) — 과거 당첨 번호 포함 강도
16. 이전 당첨 제외 (PREV_WINNER_EXCLUDE) — 과거 당첨 번호 제외 강도
17. 낙첨 패턴 회피 (LOSING_PATTERN_AVOID) — 낙첨 패턴 회피 강도

**[E] 내 필터 (3개)**
18. 내 이전번호 제외 (MY_HISTORY_EXCLUDE) — 내가 이전에 쓴 번호 제외 강도
19. 행운 번호 포함 (MY_LUCKY_NUMBER) — 사전 설정한 행운번호 포함 강도
    - 현재 설정된 행운번호 표시 + "편집" 버튼 → 번호 선택 바텀시트 (최대 10개)
20. 제외 번호 반영 (MY_EXCLUDE_NUMBER) — 사전 설정한 제외번호 반영 강도
    - 현재 설정된 제외번호 표시 + "편집" 버튼 → 번호 선택 바텀시트 (최대 10개)

---

### 4. 번호 선택 바텀시트 (19·20번 필터용)

- 1~45 (또는 로또별 최대 번호) 전체 번호 그리드 표시
- 선택/해제 토글, 최대 개수 표시
- "취소" / "확인" 버튼

---

### 5. 비용 및 생성 버튼 영역

- **비용 표시:**
  - FREE/STANDARD: "💰 비용: 100P (잔액 {포인트}P)"
  - PRO (무료 티켓 있음): "무료 티켓 사용 (남은 티켓: {n}개)"
  - PRO (무료 티켓 소진): "추가 생성 50P (잔액 {포인트}P)"
- **"🏆 번호 생성하기" 버튼**

**번호 생성 탭 시 흐름:**
1. 필터 검증 (모든 필터 0 → 에러, 필터 합산 과다 → 에러)
2. 포인트/티켓 확인
3. 확인 다이얼로그: "100P를 차감하고 번호를 생성하시겠어요?" + 현재/차감 후 포인트
4. API 호출: `POST /api/v1/picks/generate`
5. 결과 화면 전환

---

### 6. 내 생성 이력 섹션 (탭 하단)

- 최근 생성 1건 미리보기: 회차, 번호, 적중 수 표시
- "전체 이력 보기 →" 링크 → 챔피언십 이력 화면

---

## 번호 생성 결과 화면

생성 성공 후 표시되는 화면:
- "🎉 번호가 완성되었습니다!" 제목
- 로또명 + 회차 표시
- **생성된 6개 번호** (크게 표시)
- **이 번호의 특성 분석:**
  - 홀짝 비율 (조건 만족 여부 ✅)
  - 고저 비율 (✅)
  - 합계 (범위 내 여부 ✅)
  - AC값 (✅)
  - 구간 분포 (✅)
  - 소수 개수
- **포인트 차감 내역:** "-100P 차감 (잔액: {포인트}P)"
- **"한 세트 더 만들기 (100P)"** 버튼 → 같은 필터로 재생성
- **"전략 수정 후 재생성"** 버튼 → 챔피언십 탭 필터 화면으로 복귀
- **"이 전략 저장하기"** 버튼 → 전략 이름 입력 다이얼로그 → 프리셋 저장
- **"홈으로"** 버튼

## Guest 상태 화면

- 빠른 전략 프리셋 미리보기만 (탭 불가)
- 필터 슬라이더 표시되지만 비활성 (조작 불가)
- "🔒 회원가입 후 이용 가능" 안내
- "회원가입하기" 버튼

---

## 예외/에러 상태

### 필터 없음 (422 NO_ACTIVE_FILTER)

- 다이얼로그: "최소 1개 이상의 필터를 활성화해주세요"

### 필터 조건 과다 (422 FILTER_TOO_RESTRICTIVE)

- 다이얼로그: "필터 조건이 너무 많아 번호를 생성할 수 없어요. 일부 필터를 낮춰주세요."

### 포인트 부족 (402 INSUFFICIENT_POINTS)

- 다이얼로그: "포인트가 부족해요. 필요: 100P / 현재: {포인트}P"
- "스캔하러 가기" 버튼 / "포인트샵" 버튼

---

## API 연동

**번호 생성:** `POST /api/v1/picks/generate`
- 요청: game_code, draw_number, filters (20개 필터값), my_lucky_numbers, my_exclude_numbers
- 응답: pick_id, numbers, characteristics, cost_points, point_balance_after

**전략 저장:** `POST /api/v1/picks/presets`
- 요청: preset_name, filters
- 응답: preset_id, preset_name, created_at
