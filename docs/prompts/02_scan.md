# CWG 앱 — 스캔 탭 (Scan Tab) Figma Make 프롬프트

## 화면 목적

낙첨 복권을 카메라로 촬영하거나 갤러리에서 선택해 OCR로 번호를 인식하고, 검증 후 포인트를 지급하는 핵심 기능 탭.
선택적으로 광고를 시청하면 추가 포인트 획득 가능.

---

## 진입 경로

- 하단 탭 네비게이션 > "스캔"

---

## 사용자 등급별 접근/보상 차이

| 사용자 | 접근 | 기본 포인트 | 광고 시청 시 |
|--------|:----:|:---------:|:----------:|
| Guest | ❌ 회원가입 유도 | - | - |
| FREE | ✅ | +50P (1.0x) | +25P 추가 (총 75P, 1.5x) |
| STANDARD | ✅ | +75P (1.5x) | 광고 없음 |
| PRO | ✅ | +100P (2.0x) | +100P 추가 (총 200P, 4.0x) |

---

## 전체 플로우

```
[스캔 탭 진입]
    │
    ▼
[카메라 촬영] 또는 [갤러리 선택]
    │
    ▼
[OCR 인식]
    ├─ 성공 → OCR 결과 확인 화면
    └─ 실패 → [재촬영] 또는 [수동 입력]
    │
    ▼
[OCR 결과 확인] (번호 수정 가능)
    │
    ▼
[검증 중] (서버)
    ├─ 중복 → 에러
    ├─ 당첨 티켓 → 축하 메시지
    ├─ 추첨 전 → 안내
    └─ 낙첨 확인 ✅ → 기본 포인트 지급
    │
    ▼
[광고 시청 선택] (FREE/PRO만)
    ├─ 시청 → 추가 포인트 지급
    └─ 건너뛰기 → 기본 포인트만
    │
    ▼
[완료 화면]
```

## 필수 기능 요소

### 1. Guest 상태 화면

- "🔒 회원가입 후 이용 가능" 안내 메시지
- "낙첨 복권을 스캔하면 포인트를 돌려받을 수 있어요" 설명
- "회원가입하기" 버튼 → 회원가입 화면

---

### 2. 스캔 진입 화면 (로그인 상태)

- **카메라 뷰파인더:** 복권을 프레임 안에 맞춰 촬영하도록 가이드 텍스트 포함
- **촬영 버튼:** 카메라 권한 확인 후 촬영, 카메라 권한 없으면 권한 요청 안내
- **갤러리 버튼:** 갤러리에서 이미지 선택
- **"수동 입력 >" 링크:** OCR 실패 대비 수동 입력 화면으로 이동
- **일일 스캔 한도 표시:** "⚡ 일일 스캔: {오늘 스캔 수}/30" (한도 도달 시 빨간 색상)

---

### 3. OCR 결과 확인 화면

촬영/갤러리 선택 후 OCR 결과를 보여주고 사용자 확인을 받는 화면:
- **게임:** 인식된 로또 게임명 (수정 불가)
- **회차:** 인식된 회차 번호 (수정 가능, 숫자 키패드)
- **번호:** 인식된 6개 번호 (수정 가능, 숫자 키패드)
- **구매일:** 인식된 구매일 (수정 가능, 날짜 피커)
- **"수정하기" 버튼:** 개별 필드 수정 모드 진입
- **"확인" 버튼:** 검증 API 호출

---

### 4. 검증 완료 + 포인트 지급 화면

낙첨 확인 후 표시:
- ✅ 낙첨 확인됨 표시
- 기본 적립 포인트 표시 (예: +50P)
- **FREE/PRO 사용자:** 광고 시청 선택 카드 표시
  - "📺 광고 시청 (+25P)" 버튼
  - "건너뛰기" 버튼
- **STANDARD 사용자:** 광고 카드 없이 바로 완료 화면
- FREE 사용자에게 구독 유도 메시지: "구독자는 자동으로 2배 적립!"

---

### 5. 광고 시청 화면

- AdMob 광고 영역
- 남은 광고 시청 시간 표시 (예: 15초)
- "광고 시청 후 +25P 지급" 안내
- 광고 로드 실패 시: "광고를 불러오지 못했어요" → 기본 포인트만 지급

---

### 6. 완료 화면

- "🎉 스캔 완료!" 제목
- 총 획득 포인트 표시 (예: +75P)
- 구성 표시 (예: 기본 50P + 광고 25P)
- 현재 누적 포인트 잔액 표시
- "확인" 버튼
- "계속 스캔하기" 버튼 → 스캔 탭 초기 화면으로 돌아감

## 예외/에러 상태

### OCR 실패 (422 OCR_FAILED)

- 다이얼로그: "번호를 인식하지 못했어요"
- "재촬영" 버튼 / "수동 입력" 버튼

### 수동 입력

- 게임 선택 (드롭다운)
- 회차 입력 (숫자)
- 번호 6개 입력 (숫자 키패드)
- 구매일 선택 (날짜 피커)
- **수동 입력 시 포인트 50% 감산** (base_reward × 0.5 = 25P)

### 중복 티켓 (409 DUPLICATE_TICKET)

- 다이얼로그: "이 복권은 이미 등록되어 포인트를 받았어요"
- 최초 등록일과 획득 포인트 표시

### 당첨 티켓 (422 NOT_LOSING_TICKET)

- 다이얼로그: "🎉 축하합니다! 이 티켓은 당첨 티켓이에요! 등록 대상이 아닙니다"
- 당첨 번호와 내 번호, 일치 개수 표시

### 추첨 전 회차 (422 DRAW_NOT_YET)

- 다이얼로그: "아직 추첨 전이에요. 추첨일: {추첨일} 이후에 다시 시도해주세요"

### 일일 한도 초과 (429 DAILY_LIMIT_EXCEEDED)

- 다이얼로그: "오늘 스캔 한도(30회)를 모두 사용했어요. 내일 다시 스캔해주세요!"

### 계정 Lock (423 ACCOUNT_LOCKED)

- 다이얼로그: "비정상 활동이 감지되어 24시간 이용이 제한됩니다"
- Lock 해제 예정 일시 표시
- "문의하기" 버튼

## API 연동

**이미지 업로드 + OCR:** `POST /api/v1/tickets/scan`
- 요청: multipart/form-data (image, input_method: CAMERA|GALLERY)
- 응답: ocr_result (game_code, draw_number, numbers, purchase_date, confidence), s3_url

**티켓 검증 + 기본 포인트 지급:** `POST /api/v1/tickets/verify`
- 응답: ticket_id, status, is_winning, points_earned, tier_multiplier, point_balance_after, ad_boost_available, ad_boost_points

**광고 시청 완료 + 추가 포인트:** `POST /api/v1/tickets/{ticket_id}/ad-boost`
- 응답: ad_boost_points, total_points_earned, point_balance_after
