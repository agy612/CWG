# CWG 앱 — CWG 픽생성 탭 (Pick Generation) Figma Make 프롬프트

## 화면 목적

시스템이 매주 자동 생성한 CWG 픽 번호 10개 세트를 제공하는 탭.
이번 회차 예상 당첨금과 세금 후 수령액도 함께 표시.
FREE 사용자는 200P 차감 또는 구독 가입 후 열람 가능.

---

## 진입 경로

- 하단 탭 네비게이션 > "픽생성"
- 홈 화면 "이번 주 CWG 픽 미리보기 배너" > "전체 보기" 버튼

---

## 사용자 등급별 차이

| 사용자 | 픽 열람 | 조건 |
|--------|:------:|------|
| Guest | ❌ | 회원가입 필요 |
| FREE | ✅ | 200P 차감 (1회) |
| STANDARD | ✅ | 무제한 열람 |
| PRO | ✅ | 무제한 열람 |

---

## 필수 기능 요소

### 1. 헤더

- "🎯 CWG 픽생성" 제목
- 현재 선택된 로또명 + 회차 표시 (예: "한국 로또 6/45 · 제1159회")

---

### 2. 이번 회차 당첨금 정보 카드

모든 사용자에게 표시 (잠금 여부와 무관):
- **추첨일:** 예: "2026-03-01 (토)"
- **예상 1등 당첨금:** API에서 조회 (예: 25억원 추정)
- **세금 차감 후 예상 수령액:** 1등 당첨금 × (1 - tax_rate) 계산 표시 (예: 17억 5천만원, 세율 33% 적용)
- **2등 예상 당첨금:** 표시
- **면책 문구:** "당첨금은 추정치이며 실제와 다를 수 있습니다."
- **당첨금 로딩 중:** 스켈레톤 또는 스피너 표시
- **당첨금 정보 없음:** "당첨금 정보 없음" 텍스트 표시

---

### 3. 픽 10개 세트 카드 목록

#### Guest 상태

- 기본 통계 일부 공개 (최다/최소 출현 번호)
- 픽 목록 전체 잠금
- "🔒 CWG 픽을 받으려면 회원가입이 필요합니다" 안내
- "회원가입하기" 버튼

#### FREE 상태 (미결제)

- 픽 카드 10개 전체 표시, 모두 잠금 처리 (번호 대신 "?? - ?? - ?? - ?? - ?? - ??" 표시)
- 각 카드에 🔒 아이콘 표시
- 하단 열람 안내 영역:
  - "• 200P로 1회 열람"
  - "• 구독하면 무제한 열람"
  - "200P로 열람하기" 버튼
  - "구독 알아보기 →" 텍스트 링크 → 구독 화면

**200P 열람 버튼 탭 시 흐름:**
1. 포인트 잔액 확인
2. 잔액 부족 시: "포인트가 부족해요" 토스트 + "포인트샵 이동" 링크
3. 잔액 충분 시: 확인 다이얼로그 표시
   - "200P를 차감하고 이번 회차 픽 10개를 열람하시겠어요?"
   - 현재 포인트 / 차감 후 포인트 표시
   - "취소" / "열람하기" 버튼
4. API 호출: `POST /api/v1/picks/{draw_number}/unlock`
5. 픽 공개 + 햅틱 피드백

#### FREE 상태 (200P 결제 후)

- 픽 카드 10개 전체 공개
- 하단에 "다음 회차부터는 구독하면 편해요" 구독 유도 메시지
- "모든 픽 다운로드 (이미지)" 버튼
- "적중 이력 보기 →" 텍스트 링크

#### STANDARD/PRO 상태 (구독자)

- 픽 카드 10개 전체 공개
- 신뢰도 높은 Pick에 "⭐ 추천" 배지 표시 (confidence_score ≥ 0.8)
- "모든 픽 다운로드 (이미지)" 버튼
- "적중 이력 보기 →" 텍스트 링크

---

### 4. 공개된 픽 카드 내용

각 픽 카드에 표시할 정보:
- **픽 번호:** "Pick #1"
- **6개 번호:** 예: "3 - 12 - 18 - 27 - 35 - 42"
- **번호 특성 (2줄):**
  - 홀짝 비율 (예: 홀짝: 3:3)
  - 고저 비율 (예: 고저: 2:4)
  - 번호 합계 (예: 합계: 137)
  - 구간 분포 (예: 구간: 균등 분포)
- **추천 Pick:** "⭐ 추천" 배지 + "🔥 신뢰도: ★★★★☆" 표시

---

### 5. 다운로드 기능

- "모든 픽 다운로드" 버튼 탭 시 10개 픽을 1개 이미지로 합성해 갤러리에 저장
- "갤러리에 저장되었습니다" 토스트 메시지
- 픽 카드 길게 누르기 → 해당 픽 단독 이미지 저장 또는 공유

---

## API 연동

**픽 조회:** `GET /api/v1/picks/{draw_number}`
- 응답 (FREE 잠금): picks 배열의 numbers = null, is_locked = true
- 응답 (구독자/결제 후): picks 배열의 numbers = 공개, characteristics, confidence_score, is_recommended

**픽 열람 (200P 차감):** `POST /api/v1/picks/{draw_number}/unlock`
- 응답: draw_number, unlocked, points_deducted, point_balance_after
- 에러: INSUFFICIENT_POINTS

**픽 이미지 다운로드:** `GET /api/v1/picks/{draw_number}/image`
