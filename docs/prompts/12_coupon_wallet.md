# CWG 앱 — 쿠폰함 화면 (Coupon Wallet) Figma Make 프롬프트

## 화면 목적

사용자가 보유한 쿠폰을 상태별로 확인하고, 쿠폰 코드를 수동 입력해 등록하고, 쿠폰을 사용하는 화면.

---

## 진입 경로

- 마이 탭 > 쿠폰함 메뉴
- 프로모션 팝업 "쿠폰 받기" 탭 후 자동 이동

---

## 필수 기능 요소

### 1. 헤더

- "쿠폰함" 제목
- 뒤로가기 버튼

---

### 2. 쿠폰 코드 수동 입력 버튼

화면 상단에 항상 표시:
- "쿠폰 코드 입력하기 +" 버튼
- 탭 시 쿠폰 코드 입력 바텀시트 표시

---

### 3. 상태 탭 (3개)

- **사용 가능** — status=ACTIVE 쿠폰 목록
- **사용 완료** — status=USED 쿠폰 목록
- **만료** — status=EXPIRED 쿠폰 목록

탭 전환 시 해당 상태 쿠폰 목록 표시.

---

### 4. 쿠폰 카드 (사용 가능)

각 카드에 표시:
- **아이콘:** 쿠폰 유형별 (할인 🎁 / 무료 🎫 / 포인트 💰)
- **쿠폰명:** 예: "10% 할인 쿠폰"
- **설명:** 예: "구독 결제 시 10% 할인"
- **유효기간:** "유효기간: YYYY-MM-DD"
- **"사용하기" 버튼**

카드 전체 탭 (버튼 제외) → 쿠폰 상세 바텀시트 표시

---

### 5. 쿠폰 상세 바텀시트

쿠폰 카드 탭 시:
- 쿠폰명, 설명
- **사용 조건:** 상세 안내 (예: "월간/연간 구독 결제 시 적용, 1회만 사용 가능")
- **유효기간:** YYYY-MM-DD까지
- **"사용하기" 버튼**

---

### 6. 쿠폰 카드 (사용 완료)

- 카드 전체 회색 처리
- **사용일:** "사용일: YYYY-MM-DD"
- **"✓ 사용 완료"** 표시
- "사용하기" 버튼 없음

---

### 7. 쿠폰 카드 (만료)

- 카드 전체 회색 처리
- **만료일:** "만료일: YYYY-MM-DD"
- **"⚠️ 만료됨"** 표시
- "사용하기" 버튼 없음

---

### 8. 빈 상태

해당 탭에 쿠폰 없을 때:
- 🎫 아이콘
- "사용 가능한 쿠폰이 없어요"
- "프로모션에서 쿠폰을 받아보세요"

---

## 쿠폰 코드 입력 바텀시트

"쿠폰 코드 입력하기 +" 버튼 탭 시 표시:
- 제목: "쿠폰 코드 입력"
- "×" 닫기 버튼
- 안내: "프로모션 코드를 입력해주세요"
- 입력 필드 (Placeholder: "쿠폰 코드를 입력하세요", 대문자 자동 변환)
- "등록하기" 버튼 (입력 없으면 비활성)
- "등록하기" 탭 시:
  - API 호출: `POST /api/v1/coupons/register`
  - 성공: 바텀시트 닫기 + "쿠폰이 등록되었습니다!" 토스트 + 사용 가능 탭 목록 갱신
  - 실패: 에러 메시지 표시 (바텀시트 유지)

---

## 쿠폰 사용 플로우

"사용하기" 버튼 탭 시 쿠폰 유형별 동작:

| 유형 | 동작 |
|------|------|
| DISCOUNT | 구독 화면으로 이동, 할인 자동 적용 |
| TICKET | 챔피언십 번호 생성 1회 무료 처리, "챔피언십 탭에서 사용되었습니다" 토스트 |
| POINT | 즉시 포인트 지급, "{포인트}P가 지급되었습니다!" 토스트 |
| SUBSCRIPTION | 구독 무료 제공 처리, 구독 활성화 |

## 예외/에러 상태

### 쿠폰 코드 오류

| 에러 코드 | 메시지 |
|----------|--------|
| COUPON_NOT_FOUND | "존재하지 않는 쿠폰 코드입니다." |
| COUPON_ALREADY_USED | "이미 사용한 쿠폰입니다." |
| COUPON_EXPIRED | "만료된 쿠폰입니다." |
| COUPON_LIMIT_EXCEEDED | "쿠폰 사용 한도를 초과했습니다." |
| INVALID_COUPON | "유효하지 않은 쿠폰입니다." |

에러 발생 시 입력 바텀시트 내 에러 메시지 표시.

### 네트워크 오류

- "⚠️ 쿠폰을 불러올 수 없어요. 네트워크 연결을 확인해주세요."
- "다시 시도" 버튼

## API 연동

**쿠폰 목록 조회:** `GET /api/v1/coupons?status={ACTIVE|USED|EXPIRED}`
- 응답: coupons 배열 (coupon_id, code, type, title, description, discount_rate, discount_amount, status, conditions, expires_at, used_at)

**쿠폰 코드 등록:** `POST /api/v1/coupons/register`
- 요청: { "code": "ABC123DEF456" }
- 응답: coupon_id, type, title, status, expires_at

**쿠폰 사용:** `POST /api/v1/coupons/{coupon_id}/use`
- 요청: { "usage_context": "SUBSCRIPTION" | "CHAMPIONSHIP" | "POINT" }
- 응답: coupon_id, status, used_at, applied_discount, message
