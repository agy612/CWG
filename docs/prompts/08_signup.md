# CWG 앱 — 회원가입 화면 (Sign Up) Figma Make 프롬프트

## 화면 목적

기기 등록 기반 간편 회원가입 화면 (10초 완료 목표).
닉네임·이메일은 선택 입력, 필수 약관 동의만 하면 가입 완료.
가입 완료 후 첫 가입 보너스 100P 지급.

---

## 진입 경로

- 온보딩 화면 "시작하기" 탭 또는 "건너뛰기" 탭
- Guest 상태에서 "회원가입하기" 버튼 탭

---

## 필수 기능 요소

### 1. 안내 텍스트

- "기기 등록만으로 바로 시작!" 문구 표시
- MVP는 기기 ID(device_id) 기반 인증 (Phase 2에서 소셜 로그인 추가 예정)

---

### 2. 입력 필드

**닉네임 (선택)**
- 라벨: "닉네임 (선택)"
- Placeholder: "닉네임을 입력해주세요"
- 최대 10자, 한글·영문·숫자만 허용
- 입력하지 않으면 기본 닉네임 자동 생성 (예: "사용자12345")

**이메일 (선택)**
- 라벨: "이메일 (선택 — 기기 분실 복구)"
- Placeholder: "이메일을 입력해주세요"
- 이메일 형식 검증 (example@domain.com)
- 형식 오류 시 필드 하단에 에러 메시지 표시

---

### 3. 약관 동의 체크박스 (3개)

1. **이용약관 동의 (필수)** — 텍스트 탭 시 약관 상세 바텀시트 표시
2. **개인정보 처리방침 동의 (필수)** — 텍스트 탭 시 개인정보 처리방침 바텀시트 표시
3. **마케팅 수신 동의 (선택)** — 체크 시 프로모션 알림 수신

---

### 4. 가입 완료 버튼

- 필수 약관 2개 미동의 시 버튼 비활성화
- 필수 약관 동의 시 버튼 활성화
- 탭 시 API 호출 (`POST /api/v1/auth/signup`)
- **요청 데이터:** device_id, nickname, email, agreed_terms, agreed_privacy, agreed_marketing, game_code

---

### 5. 첫 가입 보너스 안내

- "🎁 첫 가입 보너스 +100P!" 문구 표시 (버튼 하단)

---

### 6. 가입 완료 화면

가입 성공 후 별도 화면으로 전환:
- "🎉 가입 완료!" 제목
- "환영합니다, {닉네임}님!" 환영 메시지
- "첫 가입 보너스로 100P를 드렸어요!" 안내
- 현재 포인트: 100P 표시
- "시작하기" 버튼 → 홈 화면으로 이동

---

## 예외/에러 상태

| 상황 | 처리 |
|------|------|
| 필수 약관 미동의 상태에서 버튼 탭 | "필수 약관에 동의해주세요" 토스트 |
| 닉네임 중복 | 다이얼로그: "이미 사용 중인 닉네임이에요" |
| 이메일 형식 오류 | 필드 하단 에러 메시지 |
| 서버 오류 | 다이얼로그: "일시적인 오류가 발생했어요. 잠시 후 다시 시도해주세요." |

---

## 약관 바텀시트

- 이용약관 또는 개인정보 처리방침 텍스트 탭 시 바텀시트로 상세 내용 표시
- 바텀시트 하단에 "동의하고 닫기" 버튼

---

## API 연동

**회원가입:** `POST /api/v1/auth/signup`
- 응답: user_id, nickname, tier(FREE), point_balance(100P), access_token, refresh_token
