# CWG 앱 — 포인트샵 화면 (Point Shop) Figma Make 프롬프트

## 화면 목적

적립한 포인트로 구독권 또는 챔피언십 티켓을 구매하는 화면.
포인트 사용처 제공, 번들 할인으로 구매 유도.

---

## 진입 경로

- 마이 탭 > 포인트샵 메뉴
- 포인트 부족 에러 메시지 내 "포인트샵에서 구매" 링크

---

## 권한

- Guest: ❌ 회원가입 필요
- FREE / STANDARD / PRO: ✅ 접근 가능

---

## 필수 기능 요소

### 1. 헤더

- "💰 포인트샵" 제목
- 뒤로가기 버튼

---

### 2. 내 포인트 잔액 표시

- "내 포인트: {잔액} P" 크게 표시 (화면 상단 고정)

---

### 3. 구독권 섹션

표시 조건: FREE는 Standard·Pro 모두 표시, STANDARD는 Pro만 표시, PRO는 숨김

**Standard 구독권 카드**
- 상품명: "Standard 구독 1개월"
- 원가 표시: "₩5,000 상당"
- 포인트 가격: "💰 5,000 P"
- 혜택 목록:
  - ✓ CWG 픽 무제한 열람
  - ✓ 스캔 포인트 1.5배
  - ✓ 광고 제거
- "구매하기" 버튼

**Pro 구독권 카드**
- 상품명: "Pro 구독 1개월"
- 원가 표시: "₩8,000 상당"
- 포인트 가격: "💰 8,000 P"
- 혜택 목록:
  - ✓ CWG 픽 무제한 열람
  - ✓ 스캔 포인트 2.0배
  - ✓ 챔피언십 1일 1회 무료
- "구매하기" 버튼

---

### 4. 챔피언십 티켓 섹션

모든 등급에서 표시:

**1회 티켓**
- 가격: "💰 100P"
- "구매하기" 버튼

**5회 묶음 (10% 할인)**
- 할인 배지: "🏷 10% 할인"
- 원가: "500P" (취소선)
- 할인가: "💰 450P"
- "구매하기" 버튼

**10회 묶음 (20% 할인) — 가장 경제적**
- 할인 배지: "🏷 20% 할인"
- 추천 표시: "⭐ 가장 경제적"
- 원가: "1,000P" (취소선)
- 할인가: "💰 800P"
- "구매하기" 버튼

---

### 5. 구매 플로우

"구매하기" 버튼 탭 시:
1. 포인트 잔액 확인
2. 잔액 부족 시: 에러 다이얼로그 (필요 포인트 / 현재 포인트 / 부족 포인트 표시) + "스캔하러 가기" 버튼
3. 잔액 충분 시: 구매 확인 다이얼로그
   - 상품명
   - "💰 {포인트}P를 사용합니다"
   - 현재 포인트 / 차감 후 포인트
   - 구독권의 경우 구독 기간 표시 (예: 2026-02-25 ~ 2026-03-25 30일)
   - "취소" / "구매하기" 버튼
4. API 호출: `POST /api/v1/point-shop/purchase`
5. 성공 → 구매 완료 화면

---

### 6. 구매 완료 화면

- "🎉 구매 완료!" 제목
- 상품명 표시 (예: "Standard 구독 1개월을 구매했어요!")
- 구독권: 구독 기간 표시
- 챔피언십 티켓: 지급된 티켓 수 + 현재 총 보유 티켓 수
- 남은 포인트 표시
- "확인" 버튼

---

### 7. 최근 구매 내역

화면 하단:
- 최근 구매 1건 미리보기 (상품명, 일자, 차감 포인트)
- "전체 내역 보기 →" 링크

---

## 예외/에러 상태

### 포인트 부족

- 다이얼로그: "💰 포인트가 부족해요"
- "필요: {n}P / 현재: {n}P / 부족: {n}P" 표시
- "스캔하러 가기" 버튼 / "닫기" 버튼

### 구매 실패

- 다이얼로그: "⚠️ 구매 실패. 처리 중 오류가 발생했어요. 포인트는 차감되지 않았습니다."
- "다시 시도해주세요"

## API 연동

**상품 목록 조회:** `GET /api/v1/point-shop/items?user_tier={tier}`
- 응답: user_point_balance, items 배열 (item_id, item_type, item_name, point_price, features, discount_rate, is_recommended)

**상품 구매:** `POST /api/v1/point-shop/purchase`
- 요청: item_id
- 응답 (구독권): purchase_id, item_type, tier, points_deducted, point_balance_after, subscription(started_at, expires_at)
- 응답 (챔피언십 티켓): purchase_id, item_type, points_deducted, point_balance_after, tickets_added, total_tickets
- 에러: INSUFFICIENT_POINTS
