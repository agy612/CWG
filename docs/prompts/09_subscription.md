# CWG 앱 — 구독 화면 (Subscription) Figma Make 프롬프트

## 화면 목적

Standard(5,000원/월) 또는 Pro(8,000원/월) 구독 상품을 판매하는 화면.
각 요금제의 혜택을 명확히 비교 표시하고 IAP 결제를 진행.

---

## 진입 경로

- 홈 화면 구독 유도 배너 "알아보기" 버튼
- 마이 탭 > 구독 관리 (또는 "구독하기") 메뉴
- 픽생성 탭 잠금 화면 "구독 알아보기 →" 링크
- 챔피언십 탭 포인트 부족 시 "구독 알아보기" 버튼
- 스캔 완료 화면 "구독하면 2배 포인트" CTA

---

## 사용자 등급별 화면 차이

| 사용자 | 표시 내용 |
|--------|----------|
| FREE | Standard/Pro 2개 요금제 + 혜택 비교 |
| STANDARD | Pro 업그레이드 안내 + 현재 구독 정보 |
| PRO | 현재 구독 관리 (해지, 갱신일 확인) |

## 필수 기능 요소

### 1. 혜택 요약 섹션

"구독하면 이런 혜택이!" 제목 아래:
- ✅ CWG 픽 무제한 열람
- ✅ 스캔 포인트 1.5x~2.0x
- ✅ 챔피언십 할인 (Pro만 1일 1회 무료)
- ✅ 광고 제거 (Standard) / 선택 가능 (Pro)
- ✅ 프리미엄 배지

---

### 2. 요금제 카드 (FREE 상태)

**Standard 카드**
- 이름: "Standard"
- 가격: "₩5,000 /월"
- 혜택 목록:
  - ✓ CWG 픽 무제한 열람
  - ✓ 스캔 포인트 1.5배
  - ✓ 광고 제거
  - ✓ 챔피언십 100P/회
- "선택하기" 버튼

**Pro 카드 (⭐ 인기 강조)**
- 이름: "Pro" + "⭐ 인기" 배지 (우상단)
- 가격: "₩8,000 /월"
- 혜택 목록:
  - ✓ CWG 픽 무제한 열람
  - ✓ 스캔 포인트 2.0배
  - ✓ 광고 선택 가능 (최대 4.0배)
  - ✓ 챔피언십 1일 1회 무료
  - ✓ Pro 전용 배지
- "선택하기" 버튼

### 5. 결제 플로우

"선택하기" 버튼 탭 시:
1. 결제 확인 다이얼로그 표시:
   - 상품명 (Standard/Pro)
   - 가격 (₩5,000 또는 ₩8,000/월)
   - "• 첫 달부터 즉시 적용"
   - "• 다음 결제일: {날짜}"
   - "• 언제든 해지 가능"
   - "취소" / "결제하기" 버튼
2. "결제하기" 탭 → IAP SDK 호출 (Google Play Billing)
3. 결제 성공 → 구독 완료 화면
4. 결제 실패 → 에러 다이얼로그

---

### 6. 구독 완료 화면 (결제 성공 후)

- "🎉 구독 완료!" 제목
- "{Standard/Pro} 회원이 되셨어요!" 메시지
- 활성화된 혜택 목록 표시
- 다음 결제일 표시
- "확인" 버튼 → 홈 화면으로 이동

## API 연동

**구독 상품 조회:** `GET /api/v1/subscriptions/plans?game_code={game_code}`
- 응답: plans 배열 (plan_id, tier, price, currency, duration_days, features, is_popular)

**구독 활성화:** `POST /api/v1/subscriptions/activate`
- 요청: plan_id, platform(GOOGLE_PLAY), purchase_token, order_id
- 응답: subscription_id, tier, started_at, expires_at, auto_renew

**구독 해지:** `POST /api/v1/subscriptions/{subscription_id}/cancel`
