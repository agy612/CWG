# CWG 앱 — 로또 선택 화면 (Lottery Selection) Figma Make 프롬프트

## 화면 목적

앱을 처음 실행하거나, 홈 화면 상단에서 로또 변경 버튼을 탭했을 때 표시되는 화면.
사용자가 이용할 로또 1개를 선택하면 그 로또가 앱 전반의 메인 컨텍스트가 됨.
선택 완료 시: 최초 실행이면 온보딩으로, 기가입 사용자면 홈으로 이동.

---

## 진입 경로

- 앱 최초 실행 (로또 미선택 상태)
- 홈 화면 상단 로또 선택 버튼 탭 (로또 변경)

---

## 필수 기능 요소

### 1. 상단 로고 + 안내 텍스트

- 앱 로고 표시 (CWG ReturnValue)
- 안내 문구: "어떤 로또를 이용하시나요?"
- 화면 상단 중앙 정렬

---

---

### 3. 카드 상태 변화

**미선택 상태:** 기본 카드 스타일

**선택됨 상태:**
- 카드 배경색 변경 (해당 로또의 Primary Color 계열)
- 카드 우상단에 ✓ 체크 아이콘 표시
- 선택 후 약 0.5초 뒤 다음 화면 자동 전환 (별도 확인 버튼 없음)

---

### 4. 당첨금 로딩 처리

- 당첨금 정보 로드 중: 해당 영역에 로딩 스켈레톤 또는 스피너 표시
- 당첨금 정보 로드 실패: "당첨금 정보 없음" 텍스트 표시 → 카드 선택은 여전히 가능

## 화면 전환 조건

| 조건 | 이동 화면 |
|------|----------|
| 최초 실행 (미가입) | 온보딩 화면 |
| 기가입 사용자 | 홈 화면 |
| 홈에서 로또 변경 후 | 홈 화면 (선택한 로또 기준으로 데이터 갱신) |

## 권한

모든 상태(Guest, FREE, STANDARD, PRO) 접근 가능. 로그인 불필요.

---

## API 연동

**로또 목록 조회:** `GET /api/v1/lotteries`
- 응답: 4개 로또의 이름, 추첨 주기, 번호 구조, 예상 당첨금, 통화 정보

**로또 선택 저장:** `POST /api/v1/users/me/lottery-selection`
- 요청: `{ "game_code": "KR_LOTTO_645" }`
- 로그인 상태에서만 호출 (Guest는 로컬에만 저장)
