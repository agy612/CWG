# CWG 앱 — 홈 탭 (Home Tab) Figma Make 프롬프트

## 앱 소개

CWG는 낙첨된 복권을 스캔하면 포인트를 돌려주는 글로벌 복권 리워드 앱입니다.
지원 로또: 한국 로또 6/45, 일본 로토6, EuroMillions, Eurojackpot.
사용자 등급: FREE / STANDARD / PRO.

---

## 화면 목적

홈 탭은 앱의 메인 대시보드입니다. 사용자가 앱을 열었을 때 가장 먼저 보는 화면으로,
자신의 포인트 현황, 당첨 픽 성과, 주요 기능 진입 버튼을 한눈에 확인합니다.

---

## 필수 기능 요소 (위에서 아래 순서)

### 1. 상단 헤더

**현재 선택된 로또 표시 + 변경 버튼**
- 사용자가 현재 어떤 로또를 보고 있는지 표시 (예: 🇰🇷 한국 로또 6/45)
- 탭하면 로또 선택 화면으로 이동해 다른 로또로 전환 가능
- 앱이 4개 로또를 지원하므로 어느 로또 기준으로 데이터를 보는지 명확히 표시

**설정 버튼**
- 우측에 설정 아이콘 → 설정 화면 이동

---

### 2. 내 포인트 현황 카드

**포인트 잔액**
- 현재 보유 포인트 수 표시 (예: 1,250 P)
- 포인트는 복권 스캔, 광고 시청, 쿠폰 등으로 적립됨
- 탭하면 포인트 적립/차감 이력 화면으로 이동

**이번 달 스캔 수**
- 이번 달 낙첨 복권 스캔한 횟수 표시 (예: 12장)
- 일일 최대 30회 한도 존재

---

### 3. 내 당첨 픽 랭킹 섹션 ← 핵심 기능

**목적:** 사용자가 과거에 받은 CWG 픽 또는 직접 만든 챔피언십 번호 중
실제 당첨 번호와 가장 많이 일치한 결과를 순위별로 보여줌

**표시 기준:**
- 실제 당첨 번호와 3개 이상 일치한 결과만 표시
- 최대 상위 3개 카드 표시
- 정렬 기준: 적중 개수 내림차순 → 회차 최신순

**각 카드에 표시할 정보:**
- 픽 유형: CWG 픽생성 세트 번호 또는 챔피언십 생성 번호 구분
- 해당 회차 (예: 제1158회)
- 내가 가진 번호 6개
- 실제 당첨 번호 6개
- 두 번호열에서 일치하는 번호 강조 표시
- 총 몇 개 일치했는지 (예: 5개 적중)
- 등수 (예: 3등)

**빈 상태:**
- 아직 당첨 픽이 없으면 안내 문구 + "픽생성 보러가기" 버튼

**전체 이력 보기 버튼:**
- 상위 3개 외 전체 이력 화면으로 이동

---

### 4. 이번 주 CWG 픽 미리보기 배너

**목적:** 이번 추첨 회차에 자동 생성된 CWG 픽 번호를 홈에서 미리 보여줌

**FREE 사용자:**
- 6개 번호 중 앞 3개만 공개, 나머지 3개는 잠금 처리
- "전체 보기" 버튼 → 픽생성 탭으로 이동 (200P 차감 또는 구독 필요)

**STANDARD/PRO 사용자:**
- 6개 번호 전체 공개
- "픽생성 탭 바로가기" 버튼

---

### 5. 챔피언십 배너

**목적:** 사용자가 직접 20개의 필터 조건을 설정해 자신만의 번호를 만드는 기능 진입 유도

**표시 내용:**
- 챔피언십 기능 소개 (나만의 전략으로 번호 생성)
- 등급별 이용 요건 표시:
  - FREE / STANDARD: 1회 생성 시 100포인트 차감
  - PRO: 하루 1회 무료, 추가 생성 시 50포인트
- "시작하기" 버튼 → 챔피언십 탭으로 이동

---

### 6. 이번 회차 공개 통계

**목적:** 플랫폼에 쌓인 데이터 기반 통계를 공개해 서비스 신뢰도 제공

**표시 정보:**
- 이번 회차 기준 총 수집된 낙첨 티켓 수 (예: 42,350장)
- 가장 많이 등장한 번호 Top 3 (Hot Numbers)
- 가장 적게 등장한 번호 Bottom 3 (Cold Numbers)

---

### 7. 최근 스캔 내역

**목적:** 내가 최근에 스캔한 복권과 획득한 포인트를 빠르게 확인

**표시 내용:**
- 최근 2~3건: 회차 + 획득 포인트 (예: 로또 6/45 제1158회 → +50P)
- "더보기" → 전체 스캔/포인트 이력 화면으로 이동

---

### 8. 구독 유도 배너 (FREE 사용자만 표시)

**목적:** FREE 사용자에게 구독의 혜택을 어필해 전환 유도

**표시 내용:**
- 구독 시 핵심 혜택 요약:
  - CWG 픽 무제한 열람
  - 스캔 포인트 1.5x (Standard) / 2.0x (Pro)
  - 광고 제거 (Standard)
- Standard: 5,000원/월, Pro: 8,000원/월
- "알아보기" 버튼 → 구독 화면으로 이동

**STANDARD 사용자:**
- 구독 배너 대신 "Pro로 업그레이드" 간략 배너 표시

**PRO 사용자:**
- 구독 배너 없음

---

### 9. 하단 탭 네비게이션

5개 탭으로 구성:
1. **홈** (현재 화면, 활성 상태)
2. **스캔** — 복권 사진 찍어 OCR로 낙첨 확인 + 포인트 획득
3. **픽생성** — 이번 주 자동 생성된 CWG 번호 10개 세트 열람
4. **챔피언십** — 필터 설정으로 나만의 번호 생성
5. **마이** — 포인트 내역, 구독 관리, 포인트샵, 쿠폰함, 설정

## API 연동 정보

홈 화면 데이터는 단일 API로 조회:
```
GET /api/v1/home/dashboard
Authorization: Bearer {token}
```

응답 포함 데이터:
- 사용자 등급(tier), 포인트 잔액, 이번 달 스캔 수
- 당첨 픽 목록 (type, draw_number, my_numbers, winning_numbers, match_count, prize_tier)
- 이번 회차 픽 미리보기 (일부 번호 null 처리)
- 플랫폼 통계 (총 티켓 수, hot/cold numbers)
- 최근 스캔 2건

## Guest (비회원) 상태

로그인하지 않은 사용자에게는 화면 구성이 다름:
- 포인트 카드 → **미표시**
- 당첨 픽 랭킹 → **미표시**
- CWG 픽 미리보기 → **전체 잠금 처리**
- 챔피언십 배너 → **로그인 유도 문구로 변경** ("회원가입하고 시작하기")
- 공개 통계 → **표시** (전체 공개 영역)
- 최근 스캔 내역 → **미표시**
- 구독 배너 → **대신 "회원가입 CTA 배너"** 표시
  - 문구: "낙첨 복권을 스캔하면 포인트를 돌려받을 수 있어요"
  - 버튼: "회원가입하고 시작하기" → 회원가입 화면으로 이동

## 인터랙션

- **Pull to Refresh:** 화면 당겨서 데이터 새로고침 (포인트, 당첨 픽, 통계 재조회)
- **당첨 픽 카드 탭:** 해당 픽 상세 이력 화면으로 이동
- **"전체 이력 보기" 탭:** 당첨 픽 전체 이력 화면으로 이동
- **각 배너 탭:** 해당 기능 탭으로 이동
- **최근 스캔 "더보기" 탭:** 포인트 이력 화면으로 이동
- **포인트 카드 탭:** 포인트 적립/차감 전체 이력 화면으로 이동
- **로또 변경 버튼:** 로또 선택 화면으로 이동 (변경 시 해당 로또 기준 데이터 리로드)
