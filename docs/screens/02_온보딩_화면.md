# 02. 온보딩 화면 (Onboarding)

> **화면명:** 온보딩 (3단계)
> **경로:** [로또 선택] → [온보딩] → [회원가입]
> **우선순위:** P1
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 앱의 **핵심 가치** 3가지 전달 (스캔, 픽생성, 챔피언십)
- 신규 사용자 **첫인상** 형성
- 회원가입 유도

### 1.2. 접근 경로

```
[로또 선택] → [온보딩 1/3] → [온보딩 2/3] → [온보딩 3/3] → [회원가입]
```

**표시 조건:**
- 앱 최초 실행 (로또 선택 후)
- 이미 본 사용자는 스킵 (로컬 저장소)

### 1.3. 특징

- 3단계 슬라이드
- 좌우 스와이프로 전환
- 하단 인디케이터 (●○○)
- "건너뛰기" 버튼 (우상단)

## 4. 인터랙션

### 4.1. 좌우 스와이프

**동작:**
- 우측 스와이프 → 다음 페이지
- 좌측 스와이프 → 이전 페이지 (2/3, 3/3만)
- 애니메이션: Slide (300ms)

### 4.2. 다음 버튼

**동작:**
- 1/3: 2/3으로 전환
- 2/3: 3/3으로 전환
- 3/3: [회원가입] 화면으로 이동

### 4.3. 건너뛰기 버튼

**동작:**
- 즉시 [회원가입] 화면으로 이동
- 온보딩 완료 플래그 저장 (로컬)

### 4.4. 인디케이터 터치

**동작:**
- 터치한 페이지로 이동 (선택)

---

## 5. 애니메이션

### 5.1. 진입 애니메이션

**페이지별:**
- **아이콘:** Scale 0.8 → 1.0 (400ms, ease-out)
- **제목:** Fade In + Slide Up (300ms, delay 100ms)
- **부제:** Fade In + Slide Up (300ms, delay 200ms)
- **버튼:** Fade In (200ms, delay 400ms)

### 5.2. 페이지 전환

**스와이프 또는 버튼:**
- **현재 페이지:** Slide Out (300ms)
- **다음 페이지:** Slide In (300ms)
- **인디케이터:** Scale 애니메이션 (200ms)

---

## 6. 상태 관리

### 6.1. 로컬 저장소

**키:** `onboarding_completed`

**값:**
- `true`: 온보딩 완료 (다음 실행 시 스킵)
- `false` 또는 없음: 온보딩 표시

### 6.2. 페이지 추적

**상태:**
- `currentPage`: 1, 2, 3
- 스와이프 또는 버튼으로 업데이트

## 10. 개발 노트

### 10.1. 구현 방식

**Flutter:**
- `PageView` 위젯 사용
- `PageController`로 페이지 제어
- `SharedPreferences`로 로컬 저장

**React Native:**
- `react-native-swiper` 라이브러리
- `AsyncStorage`로 로컬 저장

### 10.2. 캐싱

- 온보딩 완료 플래그: 로컬 저장소 (`onboarding_completed: true`)
