# 10. 포인트샵 화면 (Point Shop)

> **화면명:** 포인트샵
> **경로:** [마이 탭] → [포인트샵]
> **우선순위:** P0
> **작성일:** 2026-02-25
> **상태:** ✅ 신규

---

## 1. 화면 정보

### 1.1. 목적

- 포인트로 **구독권** 또는 **챔피언십 티켓** 구매
- 포인트 사용처 확대 (수익화 모델 다각화)
- 포인트 만료 전 소진 유도

### 1.2. 접근 경로

```
[마이 탭] → [포인트샵]
또는
[포인트 부족 시] → "포인트샵에서 구매" 링크
```

### 1.3. 권한

- **Guest:** ❌ 회원가입 필요
- **FREE/STANDARD/PRO:** ✅ 전체 접근 가능

## 7. 인터랙션

### 7.1. 구매 버튼

**동작:**
1. 포인트 잔액 확인
2. 부족 시: 에러 메시지
3. 충분 시: 구매 확인 다이얼로그
4. [구매하기] → API 호출
5. 성공 시: 구매 완료 화면

### 7.2. 구독권 활성화

**동작:**
1. API 호출 성공
2. `users.tier` 업데이트 (STANDARD 또는 PRO)
3. `subscriptions` 테이블 생성
4. 구매 완료 화면 + 홈으로 복귀

### 7.3. 챔피언십 티켓 지급

**동작:**
1. API 호출 성공
2. `championship_tickets` 테이블 업데이트
3. 티켓 개수 증가
4. 구매 완료 화면

### 8.2. 상품 구매

**API:** `POST /api/v1/point-shop/purchase`

**요청:**
```json
{
  "item_id": 1
}
```

**응답 (구독권):**
```json
{
  "purchase_id": 42,
  "item_type": "SUBSCRIPTION",
  "tier": "STANDARD",
  "points_deducted": 5000,
  "point_balance_after": 250,
  "subscription": {
    "subscription_id": 100,
    "started_at": "2026-02-25T10:00:00Z",
    "expires_at": "2026-03-25T10:00:00Z"
  }
}
```

**응답 (챔피언십 티켓):**
```json
{
  "purchase_id": 43,
  "item_type": "CHAMPIONSHIP_TICKET",
  "points_deducted": 450,
  "point_balance_after": 4800,
  "tickets_added": 5,
  "total_tickets": 8
}
```

**에러:**
```json
{
  "error": {
    "code": "INSUFFICIENT_POINTS",
    "message": "포인트가 부족합니다.",
    "detail": {
      "required": 5000,
      "current": 1200
    }
  }
}
```
