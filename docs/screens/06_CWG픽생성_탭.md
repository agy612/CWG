# 06. CWG 픽생성 탭 (Pick Generation)

> **화면명:** CWG 픽생성 탭
> **경로:** Bottom Navigation > 픽생성
> **우선순위:** P0
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 시스템이 자동 생성한 **CWG 픽 10개 세트** 제공
- **이번 회차 당첨금** 및 **세금 후 예상 수령액** 표시
- FREE 사용자: 200P 차감 또는 구독 유도
- STANDARD/PRO: 무제한 열람

### 1.2. 접근 경로

```
Bottom Navigation > [픽생성 탭]
```

### 1.3. 권한별 차이

| 사용자 | 픽 열람 | 조건 |
|--------|:------:|------|
| **Guest** | ❌ | 회원가입 필요 |
| **FREE** | ✅ | 200P 차감 (1회) |
| **STANDARD** | ✅ | 무제한 열람 |
| **PRO** | ✅ | 무제한 열람 |

## 5. 인터랙션

### 5.1. 200P 열람 버튼

**이벤트:** 버튼 터치

**동작:**
1. 포인트 잔액 확인 (balance >= 200)
2. 부족 시: "포인트가 부족해요" 토스트 + [포인트샵 이동]
3. 충분 시: 확인 다이얼로그 표시

**확인 다이얼로그:**
```
┌──────────────────────────────┐
│  CWG 픽 열람                  │
├──────────────────────────────┤
│  200P를 차감하고 이번 회차     │
│  픽 10개를 열람하시겠어요?     │
│                              │
│  현재 포인트: 1,250P          │
│  차감 후: 1,050P              │
│                              │
│  [취소]      [열람하기]       │
└──────────────────────────────┘
```

**열람 후:**
- API 호출: `POST /api/v1/picks/unlock`
- 200P 차감
- 픽 10개 표시
- 햅틱 피드백 (성공)

### 5.2. 구독 안내 버튼

**동작:** [구독 화면] 이동

### 5.3. 픽 카드 길게 누르기 (Long Press)

**동작:**
- 해당 픽만 이미지로 저장
- 또는 공유 (카카오톡, 문자)

### 5.4. 다운로드 버튼

**동작:**
- 10개 픽을 1개 이미지로 합성
- 갤러리에 저장
- "갤러리에 저장되었습니다" 토스트

  "unlocked": true,
