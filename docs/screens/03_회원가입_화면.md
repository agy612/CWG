# 03. 회원가입 화면 (Sign Up)

> **화면명:** 회원가입 (간편 가입)
> **경로:** [온보딩] → [회원가입] → [홈]
> **우선순위:** P1
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- **간편 회원가입** (10초 완료)
- 기기 등록 기반 인증
- 선택적 정보 입력 (닉네임, 이메일)

### 1.2. 접근 경로

```
[온보딩] → [회원가입] → [홈]
또는
Guest 상태 → [회원가입] 버튼 → [회원가입] → [홈]
```

### 1.3. 인증 방식

- **Phase 1 (MVP):** 기기 등록 (device_id)
- **Phase 2:** 소셜 로그인 추가 (Google, Apple, Kakao)

## 7. API 연동

### 7.1. 회원가입

**API:** `POST /api/v1/auth/signup`

**요청:**
```json
{
  "device_id": "abc123def456",
  "nickname": "럭키민수",
  "email": "user@example.com",
  "agreed_terms": true,
  "agreed_privacy": true,
  "agreed_marketing": false,
  "game_code": "KR_LOTTO_645"
}
```

**응답:**
```json
{
  "user_id": 12345,
  "nickname": "럭키민수",
  "tier": "FREE",
  "point_balance": 100,
  "access_token": "eyJhbGciOiJIUzI1...",
  "refresh_token": "eyJhbGciOiJIUzI1...",
  "created_at": "2026-02-25T10:00:00Z"
}
```

**에러:**
```json
{
  "error": {
    "code": "NICKNAME_ALREADY_EXISTS",
    "message": "이미 사용 중인 닉네임입니다."
  }
}
```

## 11. 개발 노트

### 11.1. 기기 ID 생성

**Android:**
```kotlin
val deviceId = Settings.Secure.getString(
    context.contentResolver,
    Settings.Secure.ANDROID_ID
)
```

**iOS:**
```swift
let deviceId = UIDevice.current.identifierForVendor?.uuidString
```

### 11.2. 토큰 저장

- **Access Token:** 메모리 (1시간)
- **Refresh Token:** 로컬 저장소 (30일)
