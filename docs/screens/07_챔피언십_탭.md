# 07. 챔피언십 탭 (Championship)

> **화면명:** 챔피언십 탭
> **경로:** Bottom Navigation > 챔피언십
> **우선순위:** P0
> **작성일:** 2026-02-25
> **변경사항:** "로또 요리사" → "챔피언십" 용어 변경

---

## 1. 화면 정보

### 1.1. 목적

- 사용자가 **20개 필터**를 조절하여 **나만의 번호 생성**
- **전략 프리셋** 저장 및 재사용
- FREE: 100P/세트, PRO: 1일 1회 무료

### 1.2. 접근 경로

```
Bottom Navigation > [챔피언십 탭]
```

### 1.3. 권한별 차이

| 사용자 | 접근 | 비용 |
|--------|:----:|------|
| **Guest** | ✅ | 필터 미리보기만 |
| **FREE** | ✅ | 100P/세트 |
| **STANDARD** | ✅ | 100P/세트 |
| **PRO** | ✅ | 1일 1회 무료 (추가 50P) |

### 3.3. 필터 슬라이더 (20개)

#### 3.3.1. 슬라이더 기본 스펙

```
1. 핫넘버        [====|   ] 80
```

**스펙:**
- **제목:** "1. 핫넘버" (14px SemiBold, Gray 900)
- **슬라이더:**
  - 길이: 70%
  - 높이: 4px
  - 배경: Gray 200
  - 활성: Primary (#6366F1)
  - 썸: 원형 20px, White + Primary Border
- **값:** "80" (14px Bold, Primary)
- **범위:** 0~100

**인터랙션:**
- 슬라이더 드래그 → 실시간 값 변경
- 0으로 설정 → 해당 필터 비활성 (Gray 400)

#### 3.3.2. 필터 카테고리 (5개)

**[A] 빈도 필터 (4개):**
1. 핫넘버 (HOT_NUMBER)
2. 콜드넘버 (COLD_NUMBER)
3. 듀넘버 (DUE_NUMBER)
4. 빈도 균형 (FREQUENCY_BALANCE)

**[B] 패턴 필터 (6개):**
5. 홀짝 균형 (ODD_EVEN)
6. 고저 균형 (HIGH_LOW)
7. 연번 포함 (CONSECUTIVE)
8. 구간 분포 (SECTION_SPREAD)
9. 번호 간격 (NUMBER_GAP)
10. 끝자리 배치 (EDGE_NUMBER)

**[C] 수학 필터 (4개):**
11. 합계 범위 (SUM_RANGE)
12. 소수 비율 (PRIME_RATIO)
13. AC값 (AC_VALUE)
14. 끝자리 다양성 (LAST_DIGIT_VARIETY)

**[D] 이력 필터 (3개):**
15. 이전 당첨 포함 (PREV_WINNER_INCLUDE)
16. 이전 당첨 제외 (PREV_WINNER_EXCLUDE)
17. 낙첨 패턴 회피 (LOSING_PATTERN_AVOID)

**[E] 내 필터 (3개):**
18. 내 이전번호 제외 (MY_HISTORY_EXCLUDE)
19. 행운 번호 포함 (MY_LUCKY_NUMBER)
20. 제외 번호 반영 (MY_EXCLUDE_NUMBER)

#### 3.3.3. 개인 필터 설정 (19, 20번)

```
19. 행운 번호 포함  [====|  ] 50
    설정: 7, 13, 24  [편집]

20. 제외 번호 반영  [========|]100
    설정: 4, 44      [편집]
```

**편집 버튼:**
- **배경:** Gray 100
- **텍스트:** "편집" (12px Regular, Primary)
- **터치 시:** [번호 선택 바텀시트] 표시

**번호 선택 바텀시트:**

## 7. 인터랙션

**동작:**
1. 프리셋 터치
2. 필터 값 자동 세팅 (애니메이션 300ms)
3. 햅틱 피드백

**동작:**
1. 슬라이더 드래그
2. 실시간 값 업데이트
3. 0으로 설정 시 필터 비활성 (색상 Gray)

**동작:**
1. 필터 검증 (조건 확인)
2. 포인트/티켓 확인
3. 확인 다이얼로그


4. API 호출 (번호 생성)

## 8. API 연동

### 8.1. 번호 생성

**API:** `POST /api/v1/picks/generate`

**요청:**
```json
{
  "game_code": "KR_LOTTO_645",
  "draw_number": 1159,
  "filters": {
    "HOT_NUMBER": 80,
    "COLD_NUMBER": 0,
    "DUE_NUMBER": 60,
    "FREQUENCY_BALANCE": 40,
    "ODD_EVEN": 90,
    "HIGH_LOW": 70,
    // ... (20개 필터)
  },
  "my_lucky_numbers": [7, 13, 24],
  "my_exclude_numbers": [4, 44]
}
```

**응답:**
```json
{
  "pick_id": 42,
  "draw_number": 1159,
  "numbers": [3, 12, 18, 27, 35, 42],
  "characteristics": {
    "odd_even": "3:3",
    "high_low": "2:4",
    "sum": 137,
    "ac_value": 9,
    "section_distribution": "4개 구간",
    "prime_count": 2
  },
  "cost_points": 100,
  "point_balance_after": 1150,
  "created_at": "2026-02-25T10:30:00Z"
}
```

**에러:**
```json
{
  "error": {
    "code": "FILTER_TOO_RESTRICTIVE",
    "message": "필터 조건이 너무 까다롭습니다."
  }
}
```

### 8.2. 전략 저장
