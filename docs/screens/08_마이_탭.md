# 08. 마이 탭 (My Tab)

> **화면명:** 마이 탭
> **경로:** [홈] → [마이 탭]
> **우선순위:** P1
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 사용자 **프로필 정보** 확인
- **포인트 내역** 조회 및 관리
- **구독 상태** 확인 및 관리
- 챔피언십 **럭키/제외 번호** 설정
- 앱 설정 및 고객 지원

### 1.2. 접근 경로

```
[하단 네비게이션] → [마이 탭]
```

### 1.3. 주요 기능

- 사용자 정보 카드 (닉네임, 티어 배지, 프로필 이미지)
- 포인트 잔액 및 이력
- 스캔 통계 (이번 달, 전체)
- 메뉴: 포인트샵, 구독 관리, 쿠폰함, 럭키/제외 번호, 설정, 고객센터

## 6. API 연동

### 6.1. 사용자 프로필 조회

**API:** `GET /api/v1/users/me`

**응답:**
```json
{
  "user_id": 12345,
  "nickname": "럭키민수",
  "email": "user@example.com",
  "tier": "STANDARD",
  "point_balance": 1500,
  "profile_image_url": "https://s3.../profile.jpg",
  "created_at": "2026-02-10T10:00:00Z",
  "monthly_scans": 25,
  "monthly_points_earned": 1875,
  "total_scans": 147,
  "total_points_earned": 11025
}
```

### 6.2. 포인트 거래 내역 조회

**API:** `GET /api/v1/points/transactions?page={page}&size={size}`

**응답:**
```json
{
  "transactions": [
    {
      "transaction_id": 789,
      "type": "EARN",
      "amount": 75,
      "description": "복권 스캔 보상",
      "balance_after": 1500,
      "created_at": "2026-02-25T14:30:00Z"
    },
    {
      "transaction_id": 788,
      "type": "SPEND",
      "amount": -200,
      "description": "CWG 픽 열람",
      "balance_after": 1425,
      "created_at": "2026-02-24T11:00:00Z"
    }
  ],
  "total_count": 156,
  "page": 1,
  "total_pages": 8
}
```

### 6.3. 럭키/제외 번호 조회

**API:** `GET /api/v1/users/me/preferences`

**응답:**
```json
{
  "lucky_numbers": [7, 14, 21],
  "exclude_numbers": [4, 13, 44]
}
```

### 6.4. 럭키/제외 번호 저장

**API:** `PUT /api/v1/users/me/preferences`

**요청:**
```json
{
  "lucky_numbers": [7, 14, 21, 28],
  "exclude_numbers": [4, 13]
}
```

**응답:**
```json
{
  "lucky_numbers": [7, 14, 21, 28],
  "exclude_numbers": [4, 13],
  "updated_at": "2026-02-25T15:00:00Z"
}
```

### 6.5. 로그아웃

**API:** `POST /api/v1/auth/logout`

**요청 헤더:**
```
Authorization: Bearer {access_token}
```

**요청:**
```json
{
  "refresh_token": "eyJhbGciOiJIUzI1..."
}
```

**응답:**
```json
{
  "message": "로그아웃되었습니다."
}
```

## 7. 럭키/제외 번호 설정 화면

```
┌──────────────────────────────┐
│  럭키/제외 번호 설정           │
│  ← (뒤로가기)                 │

│  🍀 럭키 번호 (선택)          │
│  챔피언십에서 우선 포함        │

│                              │
│  ❌ 제외 번호 (선택)          │
│  챔피언십에서 제외             │
│                              │
│  [4] [13] [44] [+]           │
│                              │
│  [저장]                      │
└──────────────────────────────┘
```

**럭키 번호:**
- **최대:** 5개

**제외 번호:**
- **최대:** 10개
- **칩 색상:** Red 50, Red 600 (텍스트)
- **추가 버튼:** + (터치 시 번호 선택 바텀시트)

**저장 버튼:**
- **배경:** Primary
- **텍스트:** White, 18px Bold
- **크기:** 가로 100%, 높이 56px
- **API 호출:** `PUT /api/v1/users/me/preferences`
