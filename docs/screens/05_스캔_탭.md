# 05. 스캔 탭 (Scan)

> **화면명:** 스캔 탭
> **경로:** Bottom Navigation > 스캔
> **우선순위:** P0
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 낙첨 복권을 **카메라 스캔** 또는 **갤러리에서 선택**
- OCR로 번호 인식 → 검증 → **포인트 지급**
- **광고 시청 선택** → 추가 포인트 획득 (선택적)

### 1.2. 접근 경로

```
Bottom Navigation > [스캔 탭]
```

### 1.3. 권한별 차이

| 사용자 | 접근 | 포인트 |
|--------|:----:|--------|
| **Guest** | ❌ | 회원가입 필요 |
| **FREE** | ✅ | 1.0x (기본 50P) + 광고 1.5x (75P) |
| **STANDARD** | ✅ | 1.5x (75P), 광고 제거 |
| **PRO** | ✅ | 2.0x (100P) + 광고 선택 시 4.0x (200P) |

## 2. 플로우 (Flow)

### 2.1. 전체 플로우

```
[스캔 탭 진입]
    │
    ▼
[카메라/갤러리 선택]
    │
    ├─ [카메라] → 촬영 → OCR 실행
    └─ [갤러리] → 이미지 선택 → OCR 실행
    │
    ▼
[OCR 결과 확인]
    │
    ├─ 성공 → [번호 수정 가능] → [확인 버튼]
    └─ 실패 → [수동 입력] 또는 [재촬영]
    │
    ▼
[검증 중] (Hash, 중복, 낙첨 확인)
    │
    ├─ 중복 → 409 DUPLICATE_TICKET → [종료]
    ├─ 당첨 → 422 NOT_LOSING_TICKET → [축하 메시지] → [종료]
    ├─ 추첨 전 → 422 DRAW_NOT_YET → [안내] → [종료]
    └─ 낙첨 확인 ✅
    │
    ▼
[검증 완료 + 기본 포인트 지급]
    │
    ▼
┌───────────────┴───────────────┐
│                               │
│   FREE                        │  STANDARD         │  PRO
│   +50P 지급                   │  +75P 지급        │  +100P 지급
│   ↓                           │  ↓                │  ↓
│   [광고 시청 선택]             │  [완료]           │  [광고 시청 선택]
│   ├─ 시청 → +25P (총 75P)     │                   │  ├─ 시청 → +100P (총 200P)
│   └─ 건너뛰기 → 50P만         │                   │  └─ 건너뛰기 → 100P만
│                               │
└───────────────────────────────┘
    │
    ▼
[완료 화면]
```

## 4. 컴포넌트 상세

### 4.1. 카메라 뷰파인더

**스펙:**
- **크기:** 가로 90%, 세로 자동 (16:9 비율)
- **배경:** Black
- **프레임:** 점선 White, 2px
- **가이드:** "복권을 프레임 안에 맞춰주세요" (14px Regular, White)

**권한:**
- 카메라 권한 필요
- 권한 거부 시: "카메라 권한이 필요합니다" 안내

### 4.2. 촬영/갤러리 버튼

```

└──────────┘  └──────────┘
```

**스펙:**
- **크기:** 각 48%, 높이 56px
- **배경:** Primary (#6366F1)
- **텍스트:** White, 16px Bold
- **아이콘:** 24px
- **둥글기:** 12px
- **간격:** 중간 4%

### 4.3. 수동 입력 링크

```
수동 입력 >
```

**스펙:**
- **폰트:** 14px Regular, Primary
- **정렬:** 우측 정렬

| 필드 | 스펙 | 수정 가능 |

**수정 방법:**
- 필드 터치 → 입력 모드

- 회차: 숫자 키패드

## 7. 인터랙션

### 7.1. 촬영 버튼

**동작:**
1. 카메라 권한 확인
2. 셔터 애니메이션 (Flash)
3. OCR API 호출 (로딩 스피너)
4. 결과 화면으로 전환

**애니메이션:** 300ms

### 7.2. 광고 시청 버튼

**동작:**
1. AdMob SDK 초기화
2. 광고 로드 (3~5초)
3. 광고 재생 (15~30초)
4. 시청 완료 → API 호출 (포인트 지급)
5. 완료 화면

**에러 처리:**
- 광고 로드 실패 → "광고를 불러오지 못했어요" → 기본 포인트만 지급

### 7.3. 건너뛰기 버튼

**동작:**
1. 확인 다이얼로그 (선택)
2. 즉시 완료 화면
3. 기본 포인트만 지급

## 8. API 연동

### 8.1. 이미지 업로드 + OCR

**API:** `POST /api/v1/tickets/scan`

**요청:**
```
POST /api/v1/tickets/scan
Content-Type: multipart/form-data

{
  "image": [Binary],
  "input_method": "CAMERA" | "GALLERY"
}
```

**응답:**
```json
{
  "ocr_result": {
    "game_code": "KR_LOTTO_645",
    "draw_number": 1158,
    "numbers": [3, 12, 18, 27, 35, 42],
    "purchase_date": "2026-02-12",
    "confidence": 0.95
  },
  "s3_url": "https://s3.../ticket_12345.jpg"
}
```

**에러:**
```json
{
  "error": {
    "code": "OCR_FAILED",
    "message": "번호를 인식하지 못했습니다."
  }
}
```

### 8.2. 티켓 검증 + 포인트 지급

**API:** `POST /api/v1/tickets/verify`

**요청:**
```json
{
  "game_code": "KR_LOTTO_645",
  "draw_number": 1158,
  "numbers": [3, 12, 18, 27, 35, 42],
  "purchase_date": "2026-02-12",
  "input_method": "CAMERA",
  "s3_url": "https://s3.../ticket_12345.jpg"
}
```

**응답 (낙첨, 검증 완료):**
```json
{
  "ticket_id": 12345,
  "status": "VERIFIED",
  "is_winning": false,
  "points_earned": 50,
  "tier_multiplier": 1.0,
  "point_balance_after": 1300,
  "ad_boost_available": true,
  "ad_boost_points": 25
}
```

**에러 (중복):**
```json
{
  "error": {
    "code": "DUPLICATE_TICKET",
    "message": "이미 등록된 티켓입니다.",
    "detail": {
      "registered_at": "2026-02-15T10:00:00Z",
      "points_earned": 50
    }
  }
}
```

**에러 (당첨):**
```json
{
  "error": {
    "code": "NOT_LOSING_TICKET",
    "message": "당첨 티켓입니다.",
    "detail": {
      "winning_numbers": [3, 7, 14, 24, 37, 41],
      "match_count": 3
    }
  }
}
```

### 8.3. 광고 시청 완료 + 추가 포인트

**API:** `POST /api/v1/tickets/{ticket_id}/ad-boost`

**요청:**
```json
{
  "ticket_id": 12345,
  "ad_platform": "ADMOB",
  "ad_id": "ca-app-pub-xxx"
}
```

**응답:**
```json
{
  "ticket_id": 12345,
  "ad_boost_points": 25,
  "total_points_earned": 75,
  "point_balance_after": 1325
}
```
