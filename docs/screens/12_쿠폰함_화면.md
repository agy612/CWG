# 12. 쿠폰함 화면 (Coupon Wallet)

> **화면명:** 쿠폰함
> **경로:** [마이] → [쿠폰함]
> **우선순위:** P1
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 보유 **쿠폰 목록** 확인
- 쿠폰 **상태별 분류** (사용 가능, 사용 완료, 만료)
- **쿠폰 코드** 수동 입력
- 쿠폰 **사용 및 관리**

### 1.2. 접근 경로

```
[마이 탭] → [쿠폰함]
또는
[프로모션 팝업] → [쿠폰 받기] → [쿠폰함]
```

### 1.3. 주요 기능

- 쿠폰 상태별 탭 전환 (사용 가능 / 사용 완료 / 만료)
- 쿠폰 코드 수동 입력 (프로모션 코드)
- 쿠폰 상세 정보 확인 (할인율, 유효기간, 사용 조건)
- 쿠폰 사용하기 (구독 또는 포인트샵 결제 시)

## 7. API 연동

### 7.1. 쿠폰 목록 조회

**API:** `GET /api/v1/coupons?status={status}`

**파라미터:**
- `status`: `ACTIVE` (사용 가능), `USED` (사용 완료), `EXPIRED` (만료)

**응답:**
```json
{
  "coupons": [
    {
      "coupon_id": 123,
      "code": "ABC123DEF456",
      "type": "DISCOUNT",
      "title": "10% 할인 쿠폰",
      "description": "구독 결제 시 10% 할인",
      "discount_rate": 0.10,
      "discount_amount": null,
      "status": "ACTIVE",
      "conditions": "월간/연간 구독 결제 시 적용",
      "expires_at": "2026-03-31T23:59:59Z",
      "used_at": null
    },
    {
      "coupon_id": 124,
      "code": "CHAMP2026FREE",
      "type": "TICKET",
      "title": "챔피언십 무료 쿠폰",
      "description": "챔피언십 1회 무료",
      "discount_rate": null,
      "discount_amount": 100,
      "status": "ACTIVE",
      "conditions": "챔피언십 번호 생성 시 1회 무료",
      "expires_at": "2026-02-28T23:59:59Z",
      "used_at": null
    }
  ],
  "total_count": 2
}
```

### 7.2. 쿠폰 코드 등록

**API:** `POST /api/v1/coupons/register`

**요청:**
```json
{
  "code": "ABC123DEF456"
}
```

**응답:**
```json
{
  "coupon_id": 125,
  "code": "ABC123DEF456",
  "type": "POINT",
  "title": "500P 지급 쿠폰",
  "description": "즉시 500P 지급",
  "status": "ACTIVE",
  "expires_at": "2026-12-31T23:59:59Z"
}
```

**에러:**
```json
{
  "error": {
    "code": "COUPON_NOT_FOUND",
    "message": "존재하지 않는 쿠폰 코드입니다."
  }
}
```

### 7.3. 쿠폰 사용

**API:** `POST /api/v1/coupons/{coupon_id}/use`

**요청:**
```json
{
  "usage_context": "SUBSCRIPTION"
}
```

**응답:**
```json
{
  "coupon_id": 123,
  "status": "USED",
  "used_at": "2026-02-25T15:00:00Z",
  "applied_discount": 490,
  "message": "10% 할인이 적용되었습니다."
}
```

**에러:**
```json
{
  "error": {
    "code": "COUPON_ALREADY_USED",
    "message": "이미 사용한 쿠폰입니다."
  }
}
```

## 12. 개발 노트

### 12.1. 쿠폰 만료 체크

- 서버에서 `expires_at`과 현재 시각 비교
- 만료 여부는 API 응답의 `status` 필드로 판단 (클라이언트에서 직접 계산 X)

### 12.2. 쿠폰 자동 적용

**구독 결제 시:**
```dart
// 사용 가능한 DISCOUNT 쿠폰 자동 조회
final coupons = await getCoupons(type: 'DISCOUNT', status: 'ACTIVE');
if (coupons.isNotEmpty) {
```
