## 2. 네비게이션 구조

### 2.1. 전체 네비게이션 맵

```
[앱 실행]
    │
    ▼
[로또 선택] ──→ (선택) ──→ [온보딩] ──→ [회원가입] ──→ [홈]
    │                        │ (기가입)            │
    └────────────────────────┴──────────────────→ [홈]

[홈] ──→ [스캔] ──→ [OCR 결과] ──→ [검증 완료 + 포인트]
                                        │
                          ┌─────────────┼─────────────┐
                          │             │             │
                     [광고 시청]    [건너뛰기]    [구독 CTA]
                          │             │
                     [추가 포인트]  [기본만]

[홈] ──→ [픽생성] ──→ [10개 세트 열람]
                   ──→ [당첨금 정보]

[홈] ──→ [챔피언십] ──→ [필터 설정] ──→ [번호 생성] ──→ [결과]
                    ──→ [내 생성 이력]
                    ──→ [전략 프리셋 관리]

[홈] ──→ [마이] ──→ [포인트 내역]
                 ──→ [포인트샵] ──→ [구독권/티켓 구매]
                 ──→ [구독 관리] ──→ [구독 결제]
                 ──→ [쿠폰함] ──→ [쿠폰 등록/사용]
                 ──→ [설정]
```

### 2.2. Bottom Navigation (5탭)

```
┌────────┬────────┬────────┬──────────┬────────┐
│  홈    │  스캔   │ 픽생성  │ 챔피언십  │  마이   │
│  Home  │  Scan  │  Pick  │  Champ   │  My    │
└────────┴────────┴────────┴──────────┴────────┘
```

**아이콘:**
- 홈: 🏠 (집 아이콘)
- 스캔: 📷 (카메라 아이콘)
- 픽생성: 🎯 (타겟 아이콘)
- 챔피언십: 🏆 (트로피 아이콘)
- 마이: 👤 (사람 아이콘)

**색상:**
- 선택됨: Primary Color (#6366F1)
- 미선택: Gray (#9CA3AF)

## 3. 화면 플로우 (사용자 여정)

### 3.1. 첫 사용자 여정

```
1. 앱 설치 후 실행
   ↓
2. [로또 선택] — 4개 중 1개 선택 (예: 한국 로또 6/45)
   ↓
3. [온보딩] — 3단계 소개 (스캔, 픽생성, 챔피언십)
   ↓
4. [회원가입] — 간편 가입 (기기 등록, 닉네임)
   ↓
5. 첫 가입 보너스 +100P
   ↓
6. [홈] — 대시보드 진입
   ↓
7. [스캔 탭] — 첫 복권 스캔
   ↓
8. OCR 결과 확인 → 검증 완료 → +50P 적립
   ↓
9. 광고 시청 선택 → +25P 추가
   ↓
10. [홈] → 총 175P 보유 (100P 보너스 + 75P 스캔)
```

### 3.2. Free 사용자 → 구독 전환 여정

```
1. [홈] → "CWG 픽생성" 배너 발견 (블러 처리)
   ↓
2. [픽생성 탭] → 10개 세트 확인 시도
   ↓
3. "200P로 열람" 또는 "구독" 선택지
   ↓
4. 200P로 1회 열람 (체험)
   ↓
5. "매주 픽을 받으려면 구독이 경제적" 인지
   ↓
6. [구독 화면] → Standard (5,000원) 또는 Pro (8,000원) 선택
   ↓
7. 결제 완료 → 즉시 프리미엄 전환
   ↓
8. 다음 스캔: 광고 없이 1.5x 또는 2.0x 포인트
   ↓
9. 픽생성 무제한 열람
```

### 3.3. 챔피언십 첫 이용 여정

```
1. [챔피언십 탭] 진입
   ↓
2. "빠른 전략" 중 [🔥트렌드] 선택
   ↓
3. 필터값 자동 세팅 (핫넘버 80, 홀짝균형 90 등)
   ↓
4. 일부 필터 추가 조절 (내 행운 번호 추가)
   ↓
5. [번호 생성하기] → "100P 차감됩니다" 확인
   ↓
6. 티켓 확인: FREE(100P) / STANDARD(100P) / PRO(무료 티켓 또는 50P)
   ↓
7. 생성 → 번호 세트 + 특성 분석 표시
   ↓
8. [전략 저장] → 다음에 재사용 가능
```

## 4. 화면 전환 애니메이션

### 4.1. 탭 전환

- **애니메이션:** Fade In/Out (200ms)
- **이징:** ease-in-out

### 4.2. 화면 푸시

- **애니메이션:** Slide from Right (300ms)
- **이징:** cubic-bezier(0.4, 0.0, 0.2, 1)

### 4.3. 모달 팝업

- **배경:** Black 50% opacity + Blur 4px
- **팝업:** Scale from 0.8 to 1.0 (250ms)
- **이징:** ease-out

### 4.4. 프로모션 팝업

- **등장:** Bottom to Center (400ms)
- **소멸:** Scale to 0.9 + Fade Out (200ms)

## 6. 알림 (Push Notification)

### 6.1. 알림 시나리오

| 시점 | 대상 | 내용 | 액션 |
|------|------|------|------|
| 매주 추첨 다음 날 | 전체 | "이번 주 결과가 나왔어요! 낙첨 복권을 스캔하세요 📸" | [스캔 탭] |
| 새 픽 생성 시 | STANDARD/PRO | "이번 주 CWG 픽이 준비됐어요 🎯" | [픽생성 탭] |
| 포인트 200P 도달 | FREE | "포인트로 픽을 열어볼 수 있어요!" | [픽생성 탭] |
| 7일 미접속 | 전체 | "밀린 복권이 있으신가요? 스캔하고 포인트 받으세요" | [홈] |
| 픽 일부 적중 | STANDARD/PRO | "CWG 픽 중 N개가 적중했어요! 🎉" | [홈 → 당첨 픽 랭킹] |
| 챔피언십 번호 적중 | 해당 사용자 | "직접 만든 번호에서 N개가 적중했어요! 🏆" | [홈 → 당첨 픽 랭킹] |
| 프로모션 시작 | 대상 사용자 | "특별 프로모션! 500P 지급 이벤트 🎁" | [프로모션 팝업] |
| 쿠폰 만료 7일 전 | 쿠폰 보유자 | "쿠폰이 곧 만료돼요 (D-7)" | [쿠폰함] |

### 6.2. 알림 설정

- **위치:** [마이 탭] → [설정] → [알림 설정]
- **옵션:**
  - ☑ 추첨 결과 알림
  - ☑ 새 픽 생성 알림 (구독자만)
  - ☑ 당첨 픽 알림
  - ☑ 프로모션 알림
  - ☑ 포인트 관련 알림
  - ☑ 쿠폰 만료 알림
