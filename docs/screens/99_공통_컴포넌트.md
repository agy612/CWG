## 1. 문서 정보

### 1.1. 목적

- 앱 전체에서 **재사용되는 UI 컴포넌트** 정의
- **일관된 디자인** 시스템 구축
- 디자이너/개발자 간 **명확한 스펙 공유**

### 1.2. 적용 범위

- 모든 화면 (로또 선택, 온보딩, 홈, 스캔, CWG픽, 챔피언십, 마이 등)
- iOS 및 Android 플랫폼

## 3. 버튼 컴포넌트

### 3.1. Primary 버튼

```
[버튼 텍스트]
```

**스펙:**
- **배경:** Primary (#6366F1)
- **텍스트:** White, 16px Bold
- **크기:** 가로 지정, 높이 56px (기본)
- **둥글기:** 12px (사각) 또는 28px (pill)
- **패딩:** 좌우 24px
- **그림자:** shadow-sm

**상태:**
- **Hover/Press:** Primary 600 (#4F46E5)
- **Disabled:** Gray 200 배경, Gray 400 텍스트

**예시:**
```
[시작하기]         ← 사각형 (12px)
[다음 →]          ← Pill (28px)
```
