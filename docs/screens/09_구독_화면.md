# 09. 구독 화면 (Subscription)

> **화면명:** 구독 화면
> **경로:** 여러 진입점 (홈 배너, 마이 탭, 픽생성 잠금 등)
> **우선순위:** P0
> **작성일:** 2026-02-25
> **변경사항:** FREE/SUBSCRIBER → FREE/STANDARD/PRO 3단계

---

## 1. 화면 정보

### 1.1. 목적

- **Standard** (5,000원/월) 또는 **Pro** (8,000원/월) 구독 판매
- 구독 혜택 명확히 전달
- IAP (In-App Purchase) 결제 연동

### 1.2. 접근 경로

```
여러 진입점:
- [홈] → 구독 배너 (FREE 전용)
- [픽생성] → "200P로 열람" 또는 "구독" 선택
- [챔피언십] → 포인트 부족 시 구독 유도
- [마이 탭] → [구독 관리] → [구독 가입하기]
- [스캔 완료] → "구독하면 2배 포인트" CTA
```

### 1.3. 권한별 차이

| 사용자 | 표시 내용 |
|--------|----------|
| **FREE** | 2개 구독 상품 (Standard/Pro) + 혜택 비교 |
| **STANDARD** | Pro 업그레이드 안내 |
| **PRO** | 구독 관리 (해지, 갱신일 확인) |

## 8. API 연동

### 8.1. 구독 상품 조회

**API:** `GET /api/v1/subscriptions/plans`

**요청:**
```
GET /api/v1/subscriptions/plans?game_code=KR_LOTTO_645
```

**응답:**
```json
{
  "plans": [
    {
      "plan_id": "standard_monthly",
      "tier": "STANDARD",
      "price": 5000,
      "currency": "KRW",
      "duration_days": 30,
      "features": [
        "CWG 픽 무제한 열람",
        "스캔 포인트 1.5배",
        "광고 제거",
        "챔피언십 100P"
      ]
    },
    {
      "plan_id": "pro_monthly",
      "tier": "PRO",
      "price": 8000,
      "currency": "KRW",
      "duration_days": 30,
      "is_popular": true,
      "features": [
        "CWG 픽 무제한 열람",
        "스캔 포인트 2.0배",
        "광고 선택 가능 (4.0배)",
        "챔피언십 1일 1회 무료",
        "Pro 전용 배지"
      ]
    }
  ]
}
```

### 8.2. 구독 활성화

**API:** `POST /api/v1/subscriptions/activate`

**요청:**
```json
{
  "plan_id": "standard_monthly",
  "platform": "GOOGLE_PLAY",
  "purchase_token": "xxxxx",
  "order_id": "GPA.1234.5678.9012"
}
```

**응답:**
```json
{
  "subscription_id": 42,
  "tier": "STANDARD",
  "started_at": "2026-02-25T10:00:00Z",
  "expires_at": "2026-03-25T10:00:00Z",
  "auto_renew": true
}
```

### 8.3. 구독 해지

**API:** `POST /api/v1/subscriptions/{subscription_id}/cancel`

**요청:**
```json
{
  "subscription_id": 42
}
```

**응답:**
```json
{
  "subscription_id": 42,
  "status": "CANCELLED",
  "cancelled_at": "2026-02-25T11:00:00Z",
  "expires_at": "2026-03-25T10:00:00Z"
}
```
