# 01. 로또 선택 화면

> **화면명:** 로또 선택 (Lottery Selection)
> **경로:** 앱 첫 진입 화면
> **우선순위:** P0
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 사용자가 이용할 **로또 1개를 선택**하는 첫 진입 화면
- 선택한 로또가 사용자의 **메인 컨텍스트**가 됨
- 홈 화면 상단에서 언제든 로또 변경 가능

### 1.2. 접근 경로

```
앱 실행 → [로또 선택 화면]
```

**진입 조건:**
- 앱 최초 실행 (또는 로또 미선택 상태)
- 또는 홈 화면 상단 로또 변경 버튼 터치

**진출 조건:**
- 로또 선택 완료 → [온보딩 화면] (최초 실행)
- 로또 선택 완료 → [홈 화면] (기가입 사용자)

### 1.3. 권한

- **Guest:** ✅ 접근 가능 (로또 선택 필수)
- **FREE:** ✅ 접근 가능 (로또 변경 가능)
- **STANDARD:** ✅ 접근 가능 (로또 변경 가능)
- **PRO:** ✅ 접근 가능 (로또 변경 가능)

## 5. 인터랙션

### 5.1. 카드 터치

**이벤트:** 카드 터치 (onTap)

**동작:**
1. 터치한 카드 → Selected 상태로 전환
2. 다른 카드 → Default 상태로 전환
3. 햅틱 피드백 (경량)
4. 0.5초 대기
5. 다음 화면으로 전환

**애니메이션:**
- **카드 전환:** Scale 1.0 → 0.98 → 1.0 (150ms)
- **체크 아이콘 등장:** Scale 0 → 1.0 (200ms, ease-out)

### 5.2. 화면 전환

**조건별 분기:**

| 조건 | 전환 화면 |
|------|----------|
| 최초 실행 (가입 전) | [온보딩 화면] |
| 기가입 사용자 | [홈 화면] |
| 홈에서 로또 변경 | [홈 화면] (선택 반영) |

**애니메이션:**
- **전환 방식:** Slide from Right (300ms)
- **이징:** cubic-bezier(0.4, 0.0, 0.2, 1)

