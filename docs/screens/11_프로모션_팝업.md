# 11. 프로모션 팝업 (Promotion Popup)

> **화면명:** 프로모션 팝업
> **경로:** 앱 진입 시 자동 표시 (조건부)
> **우선순위:** P0
> **작성일:** 2026-02-25
> **상태:** ✅ 신규

---

## 1. 화면 정보

### 1.1. 목적

- **프로모션 이벤트** 안내 및 유도
- **쿠폰 지급**, **포인트 지급**, **무료 티켓** 등 혜택 전달
- 어드민에서 프로모션 생성/관리

### 1.2. 노출 조건

| 조건 | 설명 |
|------|------|
| **타이밍** | 앱 진입 시, 특정 액션 후 (스캔 완료, 구독 전환 등) |
| **대상** | 프로모션별 타겟 설정 (FREE, STANDARD, PRO, 신규 가입자 등) |
| **빈도** | 1일 1회, 또는 프로모션별 설정 |
| **기간** | 프로모션 시작일~종료일 내 |

### 1.3. 프로모션 유형 (4가지)

| 유형 | 설명 | 예시 |
|------|------|------|
| **포인트 지급** | 즉시 포인트 지급 | "신규 가입 +500P" |
| **쿠폰 지급** | 쿠폰 발급 (사용자가 등록) | "챔피언십 3회 무료 쿠폰" |
| **무료 티켓** | 챔피언십 티켓 지급 | "3회 무료 티켓 증정" |
| **구독 할인** | 구독 할인 쿠폰 | "첫 달 50% 할인 쿠폰" |

## 3. 프로모션 유형별 UI

### 3.1. 포인트 지급 프로모션

```
┌────────────────────────────┐
│  🎁 특별 프로모션!          │
│  × (닫기)                  │
├────────────────────────────┤
│                            │
│  신규 가입 환영 이벤트!     │
│                            │
│  ✨ 500 포인트 즉시 지급    │
│                            │
│  회원가입을 축하드려요!     │
│  지금 바로 500P를 받아가세요│
│                            │
│  [받기]     [나중에]        │
│                            │
│  ☐ 오늘 하루 보지 않기      │
```

**특징:**
- [받기] 터치 → 즉시 포인트 지급

- 지급 후: "500P가 지급되었습니다" 토스트

## 5. 인터랙션

### 5.1. 팝업 등장 애니메이션

**동작:**
1. 배경 Fade In (200ms)
2. 팝업 Bottom → Center (400ms)
3. Scale 0.9 → 1.0 (300ms, ease-out)

### 5.2. [받기] 버튼

**동작:**
1. API 호출 (프로모션 혜택 지급)
2. 성공 시:
   - 팝업 닫기 (Scale 1.0 → 0.9, Fade Out 200ms)
   - 토스트 메시지 ("500P가 지급되었습니다")
3. 실패 시:
   - 에러 메시지 표시

### 5.3. [나중에] 버튼

**동작:**
1. 팝업 닫기 애니메이션
2. 다음 진입 시 재표시

### 5.4. "오늘 하루 보지 않기"

**동작:**
1. 체크 시 로컬 저장소에 기록
2. 다음 날까지 해당 프로모션 미표시

### 5.5. [닫기 X] 버튼

**동작:**
1. 팝업 닫기
2. 다음 진입 시 재표시

## 6. API 연동

### 6.1. 활성 프로모션 조회

**API:** `GET /api/v1/promotions/active`

**요청:**
```
GET /api/v1/promotions/active?user_tier=FREE
```

**응답:**
```json
{
  "promotions": [
    {
      "promotion_id": 1,
      "promo_type": "POINT",
      "title": "신규 가입 환영 이벤트!",
      "description": "지금 바로 받아가세요!",
      "benefits": [
        "500 포인트 즉시 지급"
      ],
      "point_amount": 500,
      "banner_image_url": "https://s3.../promo_1.jpg",
      "is_popup": true,
      "start_date": "2026-02-20T00:00:00Z",
      "end_date": "2026-03-20T23:59:59Z",
      "target_tier": ["FREE"]
    },
    {
      "promotion_id": 2,
      "promo_type": "TICKET",
      "title": "챔피언십 무료 체험!",
      "benefits": [
        "챔피언십 3회 무료 티켓"
      ],
      "ticket_count": 3,
      "is_popup": true,
      "target_tier": ["FREE", "STANDARD"]
    }
  ]
}
```

### 6.2. 프로모션 혜택 받기

**API:** `POST /api/v1/promotions/{promotion_id}/claim`

**요청:**
```json
{
  "promotion_id": 1
}
```

**응답 (포인트 지급):**
```json
{
  "promotion_id": 1,
  "promo_type": "POINT",
  "points_granted": 500,
  "point_balance_after": 1750,
  "claimed_at": "2026-02-25T10:00:00Z"
}
```

**응답 (티켓 지급):**
```json
{
  "promotion_id": 2,
  "promo_type": "TICKET",
  "tickets_granted": 3,
  "total_tickets": 5,
  "claimed_at": "2026-02-25T10:05:00Z"
}
```

**에러:**
```json
{
  "error": {
    "code": "PROMOTION_ALREADY_CLAIMED",
    "message": "이미 받은 프로모션입니다."
  }
}
```
