# 04. 홈 탭 (Home)

> **화면명:** 홈 탭
> **경로:** Bottom Navigation > 홈
> **우선순위:** P0
> **작성일:** 2026-02-25

---

## 1. 화면 정보

### 1.1. 목적

- 사용자 **대시보드**: 핵심 정보 요약 및 주요 기능 진입점
- **포인트 잔액**, **이번 달 스캔 수**, **당첨 픽 랭킹** 표시
- CWG 픽생성, 챔피언십 배너로 프리미엄 기능 유도
- **로또 변경** 버튼 (상단)

### 1.2. 접근 경로

```
Bottom Navigation > [홈 탭]
```

**기본 화면:** ✅ (앱 진입 시 기본 탭)

### 1.3. 권한별 차이

| 사용자 | 표시 내용 |
|--------|----------|
| **Guest** | 공개 통계, 회원가입 CTA |
| **FREE** | 전체 (포인트, 스캔 수, 당첨 픽, 구독 배너) |
| **STANDARD** | 전체 (광고 없음) |
| **PRO** | 전체 (광고 없음, Pro 전용 배지) |
