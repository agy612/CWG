## 2. 구독 플랜 설계

### 2.1. 플랜 구성 (2-Tier 구독)

| 항목 | FREE | **STANDARD** | **PRO** |
|------|:----:|:----:|:----:|
| 티켓 스캔 & 포인트 적립 | 50P (1.0x) | ✅ 75P (1.5x) | ✅ **100P (2.0x)** |
| 선택적 광고 보너스 | +25P (1.5x) | ❌ | ✅ +100P (4.0x) |
| CWG 픽 열람 (10개) | 포인트 차감 (200P/회차) | ✅ **무제한** | ✅ **무제한** |
| 분석 리포트 | 포인트 차감 (500P) | ✅ **무제한** | ✅ **무제한** |
| 챔피언십 (커스텀 생성) | 100P/세트 | 100P/세트 | ✅ **1일 1회 무료** (추가 50P) |
| 적중 내역 상세 | 기본만 | ✅ 전체 | ✅ 전체 |

### 2.2. 국가별 구독 가격

가격은 해당 국가의 **복권 1회 구매 비용**을 기준으로 합리적 비율로 설정한다.

#### 가격 설정 원칙

```
STANDARD ≈ 해당 국가 복권 4~5회 구매 비용
PRO ≈ STANDARD × 1.6배
```

#### 국가별 가격표 (2-Tier 구독)

| 국가 | 로또 | 1회 가격 | **STANDARD (월)** | **PRO (월)** |
|------|------|---------|:-----------:|:-----------:|
| 🇰🇷 한국 | 로또 6/45 | ₩1,000 | **₩5,000** | **₩8,000** |
| 🇯🇵 일본 | ロト6 | ¥200 | **¥980** | **¥1,580** |
| 🇪🇺 유럽 | EuroMillions | €2.50 | **€9.99** | **€15.99** |
| 🇪🇺 유럽 | Eurojackpot | €2 | €9.99 | €15.99 |

> **참고:** 동일 국가에서 여러 로또를 지원할 경우, 구독 1건으로 해당 국가 내 전체 로또 이용 가능.
> (예: 미국 구독 → Powerball + Mega Millions 모두 이용)

## 3. 포인트 이코노미 설계

### 3.1. 포인트 발행 & 소비 밸런스

**목표:** 사용자가 "포인트로 매번 사기엔 구독이 경제적"이라고 느끼도록 설계

```
[Free 사용자 기준 — 한국]

스캔 1회 = 50P 적립 (미션 수행 시 75P)
번호 추천 1세트 열람 = 200P 소비
분석 리포트 1회 = 500P 소비
로또 요리사 1회 생성 = 100P 소비 (구독자 50P, 구독자 1일 1회 무료)

→ 번호 추천 1세트 보려면 스캔 4회 필요 (미션 시 3회)
→ 로또 요리사 1회 사용하려면 스캔 2회 필요 (미션 시 2회)
→ 매주 1세트씩 보면 월 12~16회 스캔 필요
→ 구독(₩4,900)하면 무제한 + 스캔 포인트도 2배 + 로또 요리사 1일 1회 무료

결론: 주 1회 이상 번호 추천을 보거나 로또 요리사를 사용하는 사용자는 구독이 유리
```

### 3.2. 포인트 가치 환산 (내부 기준)

| 국가 | 1P 내부 환산 가치 | 비고 |
|------|------------------|------|
| 🇰🇷 한국 | ~₩1 | 100P ≈ ₩100 상당 |
| 🇺🇸 미국 | ~$0.01 | 100P ≈ $1 상당 |
| 🇯🇵 일본 | ~¥1 | 100P ≈ ¥100 상당 |

> 이 환산 가치는 내부 운영 기준이며, 사용자에게는 "포인트"로만 표시.
> 현금 환전은 기본적으로 불가 (국가별 정책으로 제어).

### 3.3. 포인트 발행 한도 관리

| 항목 | 정책 |
|------|------|
| 일일 최대 적립 | 국가별 `max_daily_registrations` × 기본량 |
| 월간 최대 적립 한도 | 설정 필요 (인플레이션 방지) |
| 포인트 만료 | 적립일로부터 12개월 |
| 이벤트 포인트 | 별도 관리 (만료 기간 단축 가능) |

## 4. 광고 수익 모델

### 4.1. 광고 유형

| 광고 유형 | 시점 | CPM 예상 (한국) | 비고 |
|----------|------|:---:|------|
| **보상형 동영상** | 스캔 완료 후 미션 선택 | ₩10,000~15,000 | 핵심 광고 수익원 |

### 4.2. 광고 수익 분배

```

  │
  ├── 플랫폼 운영비: 60~70%

  │   └── 운영 인건비
  │
  └── 사용자 보상: 30~40%
      └── 포인트 형태로 지급
```

## 5. 단위 경제 (Unit Economics)

### 5.1. 사용자 1인당 월간 시뮬레이션

#### Free 사용자 (광고 미션 수행)

```
수입:
  광고 수익: 주 2회 스캔 × 4주 = 월 8회 광고 시청
  보상형 동영상 CPM ₩12,000 기준
  월 광고 수입: 8회 × ₩12 = ₩96

비용:
  포인트 지급: 8회 × 75P × ₩1 = ₩600
  로또 요리사 사용: 월 2회 × 100P × ₩1 = ₩200 (포인트 소비이므로 지급분에서 회수)

순 포인트 유출: ₩600 - ₩200(로또 요리사 회수) = ₩400

→ Free 사용자만으로는 적자 (포인트 비용 > 광고 수익)
→ 로또 요리사 등 포인트 소비처가 포인트 인플레이션을 억제
→ Free 사용자의 핵심 가치는 "데이터 수집" + "구독 전환 파이프라인"
```

#### 구독자

```
수입:
  구독료: ₩4,900 /월
  (자발적 광고 시청 시 추가 수입)

비용:
  포인트 지급: 주 3회 × 4주 = 12회 × 100P × ₩1 = ₩1,200
  로또 요리사: 1일 1회 무료 제공 비용(가상): 월 ~20회 × 50P × ₩1 = ₩1,000
  OCR API: 12회 × ₩2 = ₩24
  서버: ₩100

  총 비용: ₩2,324
  (로또 요리사 추가 사용분은 50P 차감으로 일부 회수)

월 마진: ₩4,900 - ₩2,324 = ₩2,576 (53% 마진)
```

### 5.2. 손익분기 (Break-Even) 시나리오

```
고정비 (월간 추정):
  서버 인프라: ₩3,000,000
  OCR API (10만 건): ₩200,000
  인건비 (3명): ₩15,000,000
  기타: ₩1,800,000
  ──────────────────
  합계: ₩20,000,000 /월

손익분기 구독자 수:
  ₩20,000,000 ÷ ₩2,576(구독자 마진) ≈ 7,764명

→ 월 유료 구독자 약 7,800명이면 손익분기
```

## 6. 수익 단계별 전략

### Phase 1 (0~6개월): 데이터 확보 우선

```
[전략] 포인트를 넉넉히 지급하여 스캔 유도 → 데이터 축적
[수익] 적자 감수 (시드 투자 기간)
[KPI] 월간 스캔 수, 누적 데이터 양, DAU

- 신규 가입 보너스 100P
- 스캔 기본 지급 50P (높게 유지)
- 번호 추천은 기본 통계만 무료 공개
- 구독 미출시 (데이터 부족으로 추천 가치 낮음)
```

### Phase 2 (6~12개월): 구독 모델 론칭

```
[전략] 알고리즘 고도화 → 번호 추천 가치 증명 → 구독 전환 유도
[수익] 구독 + 광고 시작
[KPI] 구독 전환율, 구독자 리텐션, ARPU

- 번호 추천 서비스 정식 출시 (Level 2)
- 로또 요리사 서비스 출시 (F5 — 20개 필터 기반 커스텀 번호 생성)
- 구독 플랜 출시 (월간/연간)
- 적중 이력 공개 → 마케팅 활용
- 광고 미션 시스템 도입
```

### Phase 3 (12개월~): 글로벌 확장 & 데이터 자산화

```
[전략] 국가 확장, B2B 데이터 판매
[수익] 구독 + 광고 + 로또 요리사 + 데이터 라이선스
[KPI] 국가별 MAU, 글로벌 구독자 수, B2B 계약 건수

- 미국/일본 등 추가 국가 구독 출시
- B2B 데이터 분석 리포트 판매
- 포인트몰 (기프티콘 등) 오픈
```
