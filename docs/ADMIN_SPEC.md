## 2. 사용자 관리

### 2.1 사용자 검색 및 목록

닉네임, 이메일, 전화번호로 검색

```
┌──────────────────────────────────────────────────────────┐
│ 검색: [_______________] [🔍]                             │
├──────────────────────────────────────────────────────────┤
│ 닉네임      이메일           티어      상태      액션    │
├──────────────────────────────────────────────────────────┤
│ 황금사냥꾼   gold@ex.com    PRO      정상      [상세]   │
│ 행운아      lucky@ex.com   STANDARD  정상      [상세]   │
│ 복권왕      lotto@ex.com   FREE      🔒정지   [상세]   │
└──────────────────────────────────────────────────────────┘

페이지네이션: ◀ 1 2 3 4 5 ... ▶
```

## 3. 프로모션 관리

### 3.1 프로모션 목록

앱 내 팝업 프로모션 관리
```
┌──────────────────────────────────────────────────────┐
│ 현재 프로모션                                        │
├──────────────────────────────────────────────────────┤
│ ID  제목             기간              상태    액션  │
├──────────────────────────────────────────────────────┤
│ 1   신규 가입 이벤트  03/01~03/31    🟢활성  [중지]│
│ 2   구독 할인        02/14~02/28    🔴종료  [삭제]│
└──────────────────────────────────────────────────────┘

[+ 새 프로모션 추가]
```

신규 프로모션 생성 (저장 시 즉시 활성화)

```
┌─────────────────────────────────────┐
│ 프로모션 추가                        │
│                                      │
│ 제목: [___________________]         │
│                                      │
│ 내용: [___________________]         │
│       (앱 팝업에 표시될 텍스트)     │
│                                      │
│ 이미지 URL: (선택)                   │
│ [_______________________]           │
│                                      │
│ 기간:                                │
│  시작: [2026-03-10] 00:00           │
│  종료: [2026-03-31] 23:59           │
│                                      │
│ 버튼 텍스트: [쿠폰 받기]            │
│                                      │
│ 버튼 클릭하면:                       │
│  (●) 쿠폰 코드 자동 지급            │
│      코드: [WELCOME2026]            │
│  ( ) 외부 링크로 이동               │
│      URL: [____________]            │
│                                      │
│ [취소] [저장 및 활성화]             │

```
