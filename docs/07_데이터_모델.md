# 07. 데이터 모델

## 1. ERD 개요

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────────┐
│    users     │     │     tickets      │     │  transactions    │
├──────────────┤     ├──────────────────┤     ├──────────────────┤
│ PK id        │─┐   │ PK id            │─┐   │ PK id            │
│    uuid      │ │   │ FK user_id       │ │   │ FK user_id       │
│    device_id │ ├──→│    ticket_hash   │ ├──→│ FK ticket_id     │
│    tier      │ │   │    game_code     │ │   │    amount        │
│    balance   │ │   │    round_number  │ │   │    type          │

                 │   └──────────────────┘ │
                 │                        │
┌──────────────┐ │   ┌──────────────────┐ │   ┌──────────────────┐
│subscriptions │ │   │    missions      │ │   │  draw_results    │
├──────────────┤ │   ├──────────────────┤ │   ├──────────────────┤

│ FK user_id   │←┤   │ FK user_id       │ │   │    game_code     │
│    plan_type │ │   │ FK ticket_id     │←┘   │    round_number  │
│    status    │ │   │    mission_type  │     │    winning_numbers│
│    start_date│ │   │    status        │     │    draw_date     │
│    end_date  │ │   └──────────────────┘     └──────────────────┘
└──────────────┘ │
                 │   ┌──────────────────┐     ┌──────────────────┐
                 │   │ recommendations  │     │ game_configs     │
                 │   ├──────────────────┤     ├──────────────────┤
                 │   │ PK id            │     │ PK game_code     │
                 │   │    game_code     │     │    country_code  │
                 │   │    round_number  │     │    game_name     │
                 │   │    set_label     │     │    number_range  │
                 │   │    numbers       │     │    pick_count    │
                 │   │    hit_count     │     │    draw_schedule │

                 │
                 │   ┌──────────────────┐     ┌──────────────────────┐
                 │   │ country_policies │     │ user_generated_picks │
                 │   ├──────────────────┤     ├──────────────────────┤
                 └──→│ PK country_code  │  ┌──│ PK id                │
                     │    base_reward   │  │  │ FK user_id           │
                     │    sub_price_m   │  │  │    numbers           │
                     │    sub_price_y   │  │  │    filter_snapshot   │
                     │    mission_on    │  │  │    hit_count         │
                     └──────────────────┘  │  │    hit_numbers       │
                                           │  └──────────────────────┘
                                           │
                                           │  ┌──────────────────────┐
                                           │  │ user_filter_presets  │
                                           │  ├──────────────────────┤
                                           ├──│ PK id                │
                                           │  │ FK user_id           │
                                           │  │    preset_name       │
                                           │  │    filter_weights    │
                                           │  └──────────────────────┘
                                           │
                                           │  ┌──────────────────────┐
                                           │  │ user_number_settings │
                                           │  ├──────────────────────┤
                                           └──│ PK user_id           │
                                              │    lucky_numbers     │

```

## 2. 테이블 상세

### `users` — 사용자

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | |
| `uuid` | UUID | UNIQUE, NOT NULL | 외부 식별자 |
| `device_id` | VARCHAR(128) | UNIQUE, NOT NULL | 기기 식별 |
| `email` | VARCHAR(255) | UNIQUE, NULLABLE | 소셜 로그인 시 |
| `nickname` | VARCHAR(50) | NULLABLE | 표시명 |
| `tier` | VARCHAR(20) | NOT NULL, DEFAULT 'FREE' | FREE / STANDARD / PRO |
| `point_balance` | BIGINT | NOT NULL, DEFAULT 0 | 현재 포인트 잔액 |
| `country_code` | CHAR(2) | NOT NULL | ISO 3166-1 |
| `primary_game` | VARCHAR(30) | NOT NULL | 주 이용 로또 (game_code) |
| `status` | VARCHAR(20) | NOT NULL, DEFAULT 'ACTIVE' | ACTIVE / LOCKED / BANNED |
| `locked_until` | TIMESTAMPTZ | NULLABLE | Lock 해제 시각 |
| `created_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | |
| `updated_at` | TIMESTAMPTZ | NOT NULL | |

### `tickets` — 스캔된 티켓 데이터 (핵심)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `id` | BIGSERIAL | PK | |
| `user_id` | BIGINT | FK → users.id, NOT NULL | |
| `ticket_hash` | VARCHAR(64) | **UNIQUE**, NOT NULL | SHA-256 해시 |
| `game_code` | VARCHAR(30) | NOT NULL | 예: KR_LOTTO_645 |
| `round_number` | INT | NOT NULL | 회차 번호 |
| `numbers` | INT[] | NOT NULL | 선택 번호 배열 (정렬 저장) |
| `bonus_number` | INT | NULLABLE | 보너스 번호 (해당 시) |
| `raw_ocr_data` | JSONB | NOT NULL | OCR 원본 데이터 전체 |
| `image_url` | VARCHAR(500) | NOT NULL | S3 이미지 경로 |
| `input_method` | VARCHAR(20) | NOT NULL | CAMERA / GALLERY / QR / MANUAL |
| `location_lat` | DECIMAL(10,7) | NULLABLE | GPS 위도 |
| `location_lng` | DECIMAL(10,7) | NULLABLE | GPS 경도 |
| `exif_datetime` | TIMESTAMPTZ | NULLABLE | EXIF 촬영 시간 |
| `status` | VARCHAR(20) | NOT NULL, DEFAULT 'PENDING' | PENDING / VERIFIED / FRAUD / REJECTED |
| `fraud_reason` | VARCHAR(255) | NULLABLE | 차단 사유 |
| `is_losing` | BOOLEAN | NULLABLE | 낙첨 여부 (결과 확인 전 null) |
| `registered_at` | TIMESTAMPTZ | NOT NULL, DEFAULT NOW() | |

## 3. 인덱스

| 테이블 | 인덱스 | 타입 | 용도 |
|--------|--------|------|------|
| `tickets` | `ticket_hash` | UNIQUE | 중복 차단 |
| `tickets` | `(user_id, registered_at DESC)` | COMPOSITE | 사용자별 최근 조회 |
| `tickets` | `(game_code, round_number)` | COMPOSITE | 회차별 데이터 집계 |
| `tickets` | `status` | BTREE | 상태 필터 |
| `transactions` | `(user_id, created_at DESC)` | COMPOSITE | 포인트 이력 |
| `draw_results` | `(game_code, round_number)` | UNIQUE | 결과 조회 |
| `recommendations` | `(game_code, round_number)` | COMPOSITE | 추천 조회 |
| `subscriptions` | `(user_id, status)` | COMPOSITE | 활성 구독 확인 |
| `user_generated_picks` | `(user_id, created_at DESC)` | COMPOSITE | 사용자 생성 이력 조회 |
| `user_generated_picks` | `(game_code, round_number)` | COMPOSITE | 회차별 적중 평가 배치 |
| `user_filter_presets` | `(user_id)` | BTREE | 사용자별 프리셋 조회 |
| `promotions` | `(is_active, start_at, end_at)` | COMPOSITE | 활성 프로모션 조회 |
| `coupons` | `(user_id, status)` | COMPOSITE | 사용자별 쿠폰 상태 조회 |
| `coupons` | `code` | UNIQUE | 쿠폰 코드 중복 방지 |

## 4. game_code 규칙

```
형식: {국가코드}_{게임타입}_{번호구조}

예시:
  KR_LOTTO_645       한국 로또 6/45
  US_POWERBALL_569    미국 Powerball (5/69 + 1/26)
  US_MEGA_570         미국 Mega Millions (5/70 + 1/25)
  JP_LOTO6_643        일본 ロト6 (6/43)
  UK_LOTTO_659        영국 Lotto (6/59)
  EU_EUROMILLIONS_550 유럽 EuroMillions (5/50 + 2/12)
```
