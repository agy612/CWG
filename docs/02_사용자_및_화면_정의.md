# 02. 사용자 및 화면 정의

## 1. 사용자 유형

### 1.1. 등급 체계

| 등급 | 가입 조건 | 핵심 혜택 |
|------|----------|----------|
| **비회원 (Guest)** | 앱 설치만 | 앱 둘러보기, 로또 정보 열람만 가능 |
| **일반 회원 (FREE)** | 회원가입 (기기 등록) | 티켓 스캔, 기본 포인트 적립 (1.0x), 선택적 광고 보너스 (1.5x) |
| **STANDARD 구독자** | 월 ₩5,000 구독 | CWG 픽 무제한, 스캔 1.5x, 광고 제거, 챔피언십 100P |
| **PRO 구독자** | 월 ₩8,000 구독 | 픽 무제한, 스캔 2.0x (광고 선택 시 4.0x), 챔피언십 1일 1회 무료 |
| **관리자 (Admin)** | 내부 운영 | 정책 관리, 모니터링, 데이터 관리 |

### 1.2. 등급별 기능 접근 권한

| 기능 | Guest | FREE | STANDARD | PRO |
|------|:-----:|:----:|:--------:|:---:|
| 앱 둘러보기 / 로또 정보 | O | O | O | O |
| 티켓 스캔 | X | O | O | O |
| 기본 포인트 적립 | X | 50P (1.0x) | 75P (1.5x) | 100P (2.0x) |
| 선택적 광고 보너스 | X | +25P (1.5x) | 없음 | +100P (4.0x) |
| 기본 통계 (최다/최소 출현) | X | O | O | O |
| CWG 픽 세트 열람 (10개) | X | 200P/회차 | 무제한 | 무제한 |
| 상세 분석 리포트 | X | 500P | 무제한 | 무제한 |
| 챔피언십 (커스텀 번호 생성) | X | 100P/세트 | 100P/세트 | 1일 1회 무료, 추가 50P/세트 |
| 광고 | - | 있음 (선택) | 없음 | 있음 (선택, 4.0x) |

### 1.3. FREE → 구독자 전환 동기

```
FREE 사용자가 경험하는 흐름:

1. 티켓 스캔 → 포인트 받음 (좋은 경험)
2. "CWG 픽생성" 탭 발견 → 10개 번호 세트 확인 (흥미 유발)
3. 픽 열람 시도 → "구독 가입" 또는 "포인트 200P 차감" 선택지
4. 포인트로 1~2번 체험 → 구독이 경제적임을 인지
5. "챔피언십" 탭 발견 → 20개 필터로 직접 번호 생성에 대한 흥미
6. STANDARD 또는 PRO 구독 전환
```

### 1.4. Guest → Free 전환 동기

```
Guest 사용자가 경험하는 흐름:

1. 앱 설치 후 홈 화면 → 로또 정보, 통계 미리보기
2. "스캔" 탭 터치 → "회원가입 후 이용 가능합니다" 안내
3. 간편 가입 (기기 등록만, 10초)
4. 첫 스캔 성공 → +50P 적립 + 첫 가입 보너스 100P
```

> 상세 화면 설계는 `documents/screens/` 폴더 참조

```

│                    Bottom Navigation (5탭)              │
├────────┬────────┬────────┬──────────┬─────────────────┤

│  Home  │  Scan  │  Pick  │  Champ   │  My             │
└───┬────┴───┬────┴───┬────┴────┬─────┴────┬────────────┘
    │        │        │         │          │
    ▼        ▼        ▼         ▼          ▼
  홈 탭    스캔 탭  CWG픽 탭   챔피언십 탭  마이 탭
                    │         │          │
                    │         │          ├─ 포인트샵
                    │         │          ├─ 구독 관리
                    │         │          ├─ 쿠폰함
                    │         │          └─ 럭키/제외 번호

### 3.2. 화면 전환 맵

```
[앱 실행]
    │
    ▼
[로또 선택] ──→ [온보딩] ──→ [회원가입] ──→ [홈]
    │ (이미 가입)
    └──────────────────────────────────→ [홈]

[홈] ──→ [스캔] ──→ [OCR 결과 확인] ──→ [검증 완료 + 포인트]
                                              │
                              ┌────────────────┤
                              ▼                ▼
                      [미션 선택(Free)]   [즉시 완료(구독자)]
                              │
                              ▼
                      [광고 시청 / 퀴즈]

[홈] ──→ [AI추천] ──→ [추천 세트 열람] ──→ [잠금 해제(포인트/구독)]
                   ──→ [분석 리포트]
                   ──→ [적중 이력]

[홈] ──→ [로또 요리사] ──→ [필터 설정] ──→ [번호 생성] ──→ [결과 확인]
                       ──→ [내 생성 이력] ──→ [이력 상세 / 적중 확인]
                       ──→ [내 프리셋 관리]

[홈] ──→ [내정보] ──→ [포인트 내역]
                   ──→ [스캔 통계]
                   ──→ [구독 관리] ──→ [구독 결제]
                   ──→ [설정] ──→ [국가/로또 변경, 알림, 약관 등]
```

## 5. 사용자 여정 시나리오

### 시나리오 A: 첫 사용자 — 스캔 체험

```
1. 앱 설치 → 온보딩 (3장 소개)
2. 국가/로또 선택 (🇰🇷 로또 6/45)
3. 회원가입 (간편: 기기 등록, 닉네임 선택)
4. 첫 가입 보너스 +100P
5. 홈 화면 진입 → "첫 복권을 스캔해보세요!" 가이드
6. 스캔 탭 → 카메라로 낙첨 복권 촬영
7. OCR 결과 확인 → [확인] 버튼
8. "검증 완료! +50P 적립" → 축하 애니메이션
9. "추가 보상 받기" → 광고 시청 → +25P
10. 홈으로 돌아옴 → AI 추천 배너 노출 (블러)
11. 호기심에 AI추천 탭 진입 → 잠금 확인 → "다음에"
12. 로또 요리사 배너 발견 → 진입 → 필터 목록 구경
```

### 시나리오 B: 포인트로 AI 추천 열람 (Free)

```
1. 포인트 200P 이상 축적 (스캔 4회 이상)
2. AI추천 탭 → "추천 세트 A" 열기 시도
3. "200P로 열람하시겠습니까?" 팝업
4. [열람하기] → 포인트 차감 → 번호 세트 노출
5. 번호 확인 후 → "매주 받고 싶다면 구독!" CTA 노출
```

### 시나리오 C: 로또 요리사 첫 이용 (Free)

```
1. 로또 요리사 탭 진입 → 프리미엄 기능 소개 화면
2. "빠른 레시피" 중 [🔥 트렌드] 선택 → 필터값 자동 세팅
3. 필터값 일부 추가 조절 (행운 번호 추가 등)
4. [번호 요리하기] → "100P 차감됩니다" 확인
5. 번호 생성 → 결과 화면 (번호 + 특성 분석)
6. [이 레시피 저장하기] → 내 프리셋에 저장
7. 다음 회차에 [재사용] → 같은 레시피로 빠르게 생성
```

```
1. 매주 포인트 차감으로 AI 추천 열람 + 로또 요리사 사용

6. AI추천 탭: 모든 세트 + 상세 리포트 무제한 열람
7. 로또 요리사: 매일 1회 무료 생성, 추가 50P
