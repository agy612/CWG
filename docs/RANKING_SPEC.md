## 1. 개요

### 1.1 기획 목적

**왜 이 기능이 필요한가?**
- 실제 당첨 사례를 보여줌으로써 사용자 신뢰도 증대
- 역대 당첨 통계로 CWG 시스템의 신뢰성 입증
- 사용자의 참여 동기 부여 및 서비스 재방문 유도

**해결하고자 하는 문제**
- 신규 사용자: "정말 당첨자가 있나?"
- 기존 사용자: "다른 사람들은 어떻게 당첨됐지?"
- 서비스 신뢰성: "이 서비스가 믿을 만한가?"

### 1.2 핵심 UX 원칙

- **요약 → 상세**: 첫 카드에서 전체 요약, 스와이프로 개별 상세 정보 탐색
- **일관된 높이**: 모든 카드 280px 고정으로 안정적인 스크롤 경험
- **스와이프 탐색**: 좌우 스와이프로 자연스러운 탐색
- **조건부 표시**: 당첨자가 없으면 이 섹션 자체를 숨김

## 2. 홈화면 당첨자 캐러셀

### 2.1 화면 내 위치

홈 탭에서 상단 포인트 카드 바로 아래에 배치됩니다.

```
HomeTab 구조:
├── [헤더] 로또 선택 + 티어 뱃지
├── [포인트 카드] 내 포인트 / 스캔 현황
├── ★ [당첨자 캐러셀] ← 이 섹션 (신규 추가)
├── [내 당첨 픽 랭킹 TOP3] (기존)
├── [CWG 픽 프리뷰] (기존)
├── [챔피언십 배너] (기존)
├── [이번 회차 통계] (기존)
└── [최근 스캔 내역] (기존)
```

### 2.2 표시 로직 (우선순위)

다음 5가지 케이스 중 하나가 표시됩니다. 우선순위는 위에서 아래 순서입니다.

**케이스 A: 이번 주 당첨 현황 🎉**
- 조건: 이번 주 추첨에서 당첨자가 발생한 경우
- 구성: 요약 카드 1개 + 개별 당첨자 카드 N개 → 캐러셀
- 우선순위: **1순위 (최우선)**

**케이스 B: 지난주 당첨 현황 💫**
- 조건: 이번 주는 당첨자 없지만, 지난주에 당첨자가 있는 경우
- 구성: 요약 카드 1개 + 개별 당첨자 카드 N개 → 캐러셀
- 우선순위: **2순위**

**케이스 C-1: 역대 고액 당첨 순위 💎**
- 조건: 최근 2주 당첨자는 없지만, 역대 2등 이상 당첨자가 있는 경우
- 구성: 단일 카드 (TOP 3 순위 표시)
- 우선순위: **3순위**

**케이스 C-2: CWG 전체 당첨 통계 📊**
- 조건: 고액 당첨자(2등 이상)가 없지만, 3~5등 당첨자가 있는 경우
- 구성: 단일 카드 (전체 통계 요약)
- 우선순위: **4순위**

**케이스 D: 이번 주 참여 현황 📊**
- 조건: 당첨자가 전혀 없을 때 (서비스 초기 포함)
- 구성: 단일 카드 (참여 통계)
- 우선순위: **5순위 (최하위, 폴백)**

### 2.3 표시 로직 흐름도

```
시작
  │
  ▼
이번 주 당첨자 있음?
  │
  ├─ YES → [케이스 A] 이번 주 당첨 현황 캐러셀
  │
  └─ NO → 지난주 당첨자 있음?
            │
            ├─ YES → [케이스 B] 지난주 당첨 현황 캐러셀
            │
            └─ NO → 역대 2등 이상 당첨자 있음?
                      │
                      ├─ YES → [케이스 C-1] 역대 고액 당첨 순위
                      │
                      └─ NO → CWG 전체 당첨자 있음? (3~5등)
                                │
                                ├─ YES → [케이스 C-2] CWG 전체 당첨 통계
                                │
                                └─ NO → [케이스 D] 이번 주 참여 현황
```

## 3. 케이스별 상세 화면

### 케이스 A: 이번 주 당첨 현황 🎉

#### 3.1 구조

당첨자가 3명인 경우 총 4개 카드로 구성:
```
[카드 1] 요약 카드
[카드 2] 첫 번째 당첨자 상세
[카드 3] 두 번째 당첨자 상세
[카드 4] 세 번째 당첨자 상세

→ 캐러셀 (페이지 인디케이터: ● ○ ○ ○)
```

#### 3.2 카드 1: 요약 카드

**목적**: 이번 주 전체 당첨 현황을 한눈에 파악

**높이**: 280px 고정

```
┌─────────────────────────────────────────────┐
│ 🎉 이번 주 당첨자 발생!              ● ○ ○ ○│
├─────────────────────────────────────────────┤
│                                              │
│             🏆 총 3명 당첨                   │
│                                              │
│          3등 × 1명    4등 × 2명              │
│                                              │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
│                                              │
│        💰 총 당첨금: 1,600,000원             │
│        📅 제1159회 · 3월 15일 추첨           │
│                                              │
└─────────────────────────────────────────────┘
```

**표시 정보**
- 총 당첨자 수
- 등수별 인원 (예: 3등 × 1명, 4등 × 2명)
- 총 당첨금 (모든 당첨자의 당첨금 합계)
- 회차 및 추첨일

**인터랙션**
- 좌우 스와이프: 개별 당첨자 카드로 이동
- 페이지 인디케이터(점) 탭: 원하는 카드로 바로 이동

#### 3.3 카드 2~N: 개별 당첨자 상세

**목적**: 각 당첨자의 구체적인 정보 제공

**높이**: 280px 고정

```
┌─────────────────────────────────────────────┐
│ 🎉 이번 주 당첨자 #1                 ○ ● ○ ○│
├─────────────────────────────────────────────┤
│                                              │
│              🥇 행운*** 님                   │
│                                              │
│           💰 1,500,000원 (3등)               │
│                                              │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   │
│                                              │
│        📋 챔피언십 - 트렌드                  │
│        📅 제1159회 · 3월 9일                 │
│                                              │
└─────────────────────────────────────────────┘
```

**표시 정보**
- 닉네임 (개인정보 보호를 위해 뒤 3자리 마스킹)
- 당첨 금액 및 등수
- 생성 방법
  - CWG 픽: "CWG 픽 #3"
  - 챔피언십: "챔피언십 - 트렌드" (전략명 표시)
- 회차 및 번호 생성일

**메달 표시 규칙**
- 첫 번째 당첨자: 🥇
- 두 번째 당첨자: 🥈
- 세 번째 당첨자: 🥉
- 네 번째 이후: 번호만 표시

## 4. 디자인 가이드

### 4.1 디자인 철학

기존 manual_entry 페이지의 세련된 디자인을 기반으로 합니다.

**핵심 원칙**
- **깊이감**: 그라데이션, 그림자, 테두리를 활용한 입체감
- **부드러움**: 큰 모서리 둥글기 (24px)
- **반응성**: 터치/탭 시 자연스러운 애니메이션
- **일관성**: 전체 앱의 dark theme 톤앤매너 유지
- **가독성**: 적절한 여백과 타이포그래피 계층

### 4.2 카드 공통 디자인

**배경**
- 어두운 배경 (#1a1a1a)
- 얇은 흰색 테두리 (투명도 5%)
- 모서리 둥글기: 24px
- 내부 여백: 32px

**호버/터치 효과**
- 테두리 밝기 증가 (투명도 5% → 10%)
- 위로 2px 이동
- 그림자 생성 (깊이감)

**고정 높이**
- 모든 카드: 280px 고정
- 내용이 부족하면 여백으로 조정
- 내용이 많으면 생략하거나 줄여서 표시

### 4.3 케이스별 배경 색상

**케이스 A: 이번 주 당첨 현황**
- 그라데이션: 청록색 → 골드
- 컬러: #14b8a6 → #D4AF37
- 분위기: 밝고 화려함 (당첨 축하)

**케이스 B: 지난주 당첨 현황**
- 그라데이션: 회색 톤
- 컬러: #3a3a3a → #1a1a1a
- 분위기: 차분함 (과거 기록)

**케이스 C-1: 역대 고액 당첨 순위**
- 그라데이션: 골드
- 컬러: #D4AF37 → #FFD700
- 분위기: 고급스러움 (고액 당첨)

**케이스 C-2, D: 통계 카드**
- 그라데이션: 어두운 톤
- 컬러: #1a1a1a → #0a0a0a
- 분위기: 안정적인 정보 전달

### 4.4 등수별 아이콘 색상

- **1등**: 골드 (#FFD700)
- **2등**: 실버 (#C0C0C0)
- **3등**: 틸 (#14b8a6)
- **4등**: 노랑 (#FDD835)
- **5등**: 회색 (#9E9E9E)

### 4.5 타이포그래피 계층

**카드 타이틀**
- 크기: 16px
- 굵기: Bold (700)

**메인 숫자 (요약 카드)**
- 크기: 36px

### 6.1 당첨자 공개 정책

**공개 조건**
