### 1.4. 포인트 획득 플로우 명확화

**기존 (애매):**
```
낙첨 입력 → 기본 포인트
         → 미션 선택 (광고/퀴즈) → 추가 포인트
         → 구독자는 Free Pass (자동 2배)
```

**변경 (명확화):**
```
낙첨 입력 → 검증 완료 → 기본 포인트 지급
                    ↓
            ┌───────┴───────┐
            │  추가 획득 선택  │
            │  (선택적)       │
            └───────┬───────┘
                    ↓
    ┌───────────────┼───────────────┐
    │                               │
[광고 시청]                      [건너뛰기]
    │                               │
추가 포인트 획득                  기본 포인트만
(FREE: +50%, Pro: +100%)
```

**핵심:**
- 기본 포인트는 **무조건 지급**
- 광고는 **선택 사항** (강제 아님)
- 광고 시청 → 추가 포인트 (기존 "미션 부스트" 개념 유지)
