# 01. 서비스 개요

## 1. 서비스명

**CWG ReturnValue** (가칭)

- 앱스토어 노출명: 검토 필요 (예: "로또환원", "LottoBack", "TicketValue" 등)

## 2. 한 줄 정의

> 낙첨 복권을 스캔하면 포인트를 돌려받고, 축적된 데이터로 만든 CWG 픽 추천을 받는 글로벌 플랫폼

## 3. 핵심 루프 (Core Loop)

```
사용자가 복권 구매
       │
       ▼
  낙첨 확인
       │
       ▼
  앱으로 스캔 ──────────────────── [데이터 수집]
       │                              │
       ▼                              ▼
  포인트 리워드 획득              플랫폼 데이터 축적
       │                              │
       ▼                              ▼
  포인트로 사용                  알고리즘 고도화
  ├─ CWG 픽 열람 (포인트 차감)          │
  ├─ 챔피언십으로 나만의 번호 만들기     │
  ├─ 포인트샵에서 구독권/챔피언십 티켓 구매│
  └─ 구독 가입                          │
                                      ▼
                               CWG 픽 추천 서비스
                               (구독 / 포인트)
```

**핵심 가치 순환:**
1. 사용자가 낙첨 데이터를 제공할수록 → 알고리즘이 정교해짐
2. 알고리즘이 좋아질수록 → 구독/번호 추천 가치가 올라감
3. 번호 추천 가치가 올라갈수록 → 더 많은 사용자 유입 & 데이터 제공

## 4. 서비스가 해결하는 문제

| # | 문제 | 해결 |
|---|------|------|
| 1 | 낙첨 복권 = 가치 0원, 100% 폐기 | 스캔하면 포인트로 돌려받음 |
| 2 | 번호 선택 시 객관적 데이터 근거 없음 | 실제 낙첨 데이터 기반 알고리즘 번호 추천 |
| 3 | 전 세계 로또 데이터가 체계적으로 수집된 적 없음 | 글로벌 낙첨 데이터 축적 → 자산화 |

## 5. 서비스 범위

### 취급 대상

| 카테고리 | 지원 로또 | game_code | Phase |
|----------|---------|-----------|-------|
| **복권 (Lottery)** | 한국 동행복권 (로또 6/45) | `KR_LOTTO_645` | Phase 1 (MVP) |
| | 일본 로또6 (ロト6) | `JP_LOTO6_643` | Phase 1 |
| | 유럽 EuroMillions | `EU_EUROMILLIONS_550` | Phase 1 |
| | 유럽 Eurojackpot | `EU_EUROJACKPOT_550` | Phase 1 |
| **즉석 복권** | 스크래치 카드 등 | - | Phase 2~ |
| **스포츠 베팅** | 스포츠토토, 프로토 등 | - | Phase 3~ |

### 취급하지 않는 것

- 당첨 복권 환전/매매
- 복권 직접 구매 대행
- 도박 유도/촉진 행위

## 6. 서비스 구성 요소

```
┌─────────────────────────────────────────────────────┐
│                    CWG ReturnValue                   │
├─────────────────────────────────────────────────────┤
│                                                     │
│  [1] 티켓 스캔 & 데이터 수집                           │
│      낙첨 복권 스캔 → OCR 추출 → 검증 → 저장            │
│                                                     │
│  [2] 리워드 시스템                                    │
│      스캔 보상 포인트 지급, 선택적 광고 보너스             │
│                                                     │
│  [3] CWG 픽생성 (번호 추천 알고리즘)                   │
│      수집된 데이터 기반 번호 조합 추천 (회차당 10개 고정)   │
│                                                     │
│  [3-B] 챔피언십 (커스텀 필터 번호 생성) ★ 프리미엄      │
│      사용자가 직접 20개 필터 조합을 선택하여 나만의       │
│      번호를 생성하는 프리미엄 기능 (포인트 차감/구독 포함)  │
│                                                     │
│  [4] 구독 서비스 (2-Tier)                            │
│      STANDARD/PRO 구독 → 픽생성 무제한 + 포인트 배수 증가  │
│                                                     │
│  [5] 포인트 이코노미                                   │
│      포인트 획득/사용/교환 경제 체계                      │
│                                                     │
│  [6] 포인트샵                                         │
│      포인트로 구독권, 챔피언십 티켓 구매                  │
│                                                     │
│  [7] 프로모션 시스템                                   │
│      4가지 타입 (포인트/쿠폰/티켓/할인) 프로모션 팝업       │
│                                                     │
│  [8] 글로벌 로또 취급 (4개 지원)                        │
│      한국, 일본, EuroMillions, Eurojackpot 동시 지원     │
│      국가별 로또 규칙, 구독 가격, 정책 차등 적용           │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 7. 앱 및 서버 플랫폼

| 구분 | 기술 | 비고 |
|------|------|------|
| **앱 (클라이언트)** | Flutter (Dart) | Android MVP 우선, iOS는 Phase 2에서 동일 코드베이스로 배포 |
| **서버 (백엔드)** | Java 17+ / Spring Boot 3.x | MSA 아키텍처 (Ticket, Reward, Algorithm 서비스) |
| **API Gateway** | Spring Cloud Gateway | JWT 인증, Rate Limiting |
| **데이터베이스** | PostgreSQL 15+ | JSONB 활용 (OCR 메타데이터) |
| **캐시/정책** | Redis 7+ | Rate Limit 카운터, 정책 캐싱 |
| **메시지 브로커** | Apache Kafka | 서비스 간 비동기 이벤트 |
| **스토리지** | AWS S3 | 이미지 원본 저장 |
| **OCR** | Google Cloud Vision API | 1차, Naver Clova 백업 |

> 상세 기술 스택 및 MSA 구성은 `06_시스템_아키텍처.md` 참조
