# FULIF UI

FULIF 서비스의 UI 프로토타입입니다. Next.js + React + Tailwind CSS 기반으로 제작되었습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.

## 프로젝트 구조

```
components/   공통 컴포넌트 (팝업, 스플래시, 플랜 선택 등)
contexts/     전역 상태 (유저, 테마)
pages/        화면별 페이지 및 탭 (홈/스캔/픽생성/콘텐츠/마이 등)
public/       이미지 등 정적 리소스
styles/       전역 스타일 (테마 시스템 포함)
```

## 주요 화면

- 홈 / 스캔 / 픽 생성 / 콘텐츠 / 마이 탭
- 온보딩, 회원가입, 로그인, 튜토리얼
- AI 리그, AI 피커, AI 스캐너, 넘버센스, 행운번호
- 포인트샵, 포인트 내역, 쿠폰함, 구독 관리
- 출석 체크, 초대, 경품 응모/결과, 챗봇
